## Степень двойки

> Дано число `x`. Требуется определить, является ли `x` степенью двойки.

**Алгоритм:**

Побитовое И для `x` и `(x - 1)` должно возвращать `0`.

**Пояснение** и **Пример:**

Побитовое И (AND) между двумя числами возвращает 1 только в тех позициях, где оба числа имеют 1 в соответствующих битах. 
Рассмотрим различные примеры.

а) Степень двойки

В общем случае, если \\(x = 2^n\\), то в двоичном представлении x будет выглядеть как \\(1000...0\\) (один бит 1 и n нулей).
Когда мы вычитаем 1 из степени двойки, то получаем число, 
у которого все биты правее (младшие) установленного бита 1 становятся 1, а сам бит 1 становится 0.
Теперь рассмотрим побитовое И между `x` и `(x - 1)`:
Для \\(x = 2^n\\):

- \\(x = 1000...0\_2\\)
- \\(x - 1 = 0111...1\_2\\)
- \\(x \& (x - 1) = 1000...0\_2 \& 0111...1\_2 = 0000...0\_2\\)

Результат равен 0.

б) Другие числа

Теперь рассмотрим, что происходит, если x не является степенью двойки:

Если x имеет более одного бита, установленного в 1, то при вычитании 1 мы не получим все нули в результате побитового И. Например:
Пусть x = 6 (в двоичном: \\(0110\_2\\)):

- \\(x - 1 = 5\\) (в двоичном: \\(0101\_2\\))
- \\(x \& (x - 1) = 0110\_2 \& 0101\_2 = 0100\_2\\) (результат не равен 0).
  
в) 
   
Таким образом, побитовое И между `x` и `(x - 1)` возвращает `0` только в случае, если `x` является степенью двойки, 
потому что только в этом случае у `x` есть ровно один установленный бит, 
и вычитание `1` приводит к тому, что все биты становятся `0`. 
В других случаях, когда `x` имеет более одного установленного бита, 
результат побитового И будет отличен от `0`.

**Оценка:**

- **Время** - O(1)
- **Память** - O(1)

**Код:**

```dotty
def isPowerOfTwo(x: Int): Boolean = (x & (x - 1)) == 0

isPowerOfTwo(16) // true
```

**Метрики:**

Определение, является ли число степенью двойки, для первых миллиарда чисел занимает 4,5 секунды.
Результаты аналогичны тому, как если бы мы просто прошлись по коллекции в миллиард элементов и ничего не делали.

```dotty
(1 to 1_000_000_000).foreach: i =>
  isPowerOfTwo(i)

// Число тестовых запусков = 10
// Среднее время = 194,439 миллисекунд      
```

## Количество битовых единиц

> Даны два числа, `x` и `y`. Требуется определить, содержат ли они одинаковое количество единиц в битовом представлении.

**Алгоритм:**

- **Шаг 1** (Проверка на ноль): Если одно из чисел равно нулю, то они  имеют одинаковое количество единиц в битовом представлении только если оба равны 0.
- **Шаг 2** (Проверка четности и нечетности): Если одно из чисел четное, а другое нечетное, то делим четное число на 2 и возвращаемся к **Шагу 1**.
- **Шаг 3** (Рекурсивный вызов): Если оба четные или оба нечетные,
  то делим оба числа на 2 и возвращаемся к **Шагу 1**.

**Пример:**

Рассмотрим пример расчета для пары (6, 3):

- x = 6 (четное), y = 3 (нечетное) → возвращаемся в начало алгоритма с парой (3, 3).
- x = 3 (нечетное), y = 3 (нечетное) → возвращаемся с (1, 1).
- x = 1 (нечетное), y = 1 (нечетное) → возвращаемся с (0, 0).
- x = 0, y = 0 → возвращаем true.

Таким образом, для пары (6, 3) алгоритм вернет `true`.

**Пояснение:**

- **Шаг 1** (Проверка на ноль): Если оба числа равны нулю, то они оба не содержат единиц в битовом представлении.
  Если тольно одно из чисел равно нулю (нет единиц в битовом представлении), 
  то второе содержит как минимум одну единицу в битовом представлении. 
  А это означает, что количество единиц в битовом представлении не одинаково.
- **Шаг 2** (Проверка четности и нечетности): Если числа имеют разную четность, то при делении четного числа на 2 
  количество единиц в его битовом представлении не меняется (удаляется конечный ноль).
- **Шаг 3** Если числа имеют одинаковую четность, то они заканчиваются на одну и ту же цифру (0 или 1) в битовом представлении.
  А это означает, то при делении на два количество единиц в их битовом представлении либо не изменится, либо уменьшиться на 1
  для обоих чисел. А значит, ответ на вопрос, содержат ли они одинаковое количество единиц в битовом представлении,
  равносильно вопросу, содержат ли они одинаковое количество единиц в битовом представлении после отсечения последней цифры.

**Оценка:**

- **Время** - O(log(n))
- **Память** - O(1)

**Код:**

```dotty
@annotation.tailrec
def isSnoob(x: Int, y: Int): Boolean = 
  if x == 0 && y == 0 then true
  else if x == 0 || y == 0 then false
  else if x % 2 == 1 && y % 2 == 0 then isSnoob(x, y >> 1)
  else if x % 2 == 0 && y % 2 == 1 then isSnoob(x >> 1, y)
  else isSnoob(x >> 1, y >> 1)

isSnoob(11, 13)
// true: "1101", "1011"  
```

**Метрики:**

Проверка для первых 10000 пар занимает 4 секунды.

```dotty
@main def isSnoobBench(): Unit =
  val limit = 10_000
  (1 until limit).foreach: i =>
    (i + 1 to limit).foreach: j =>
      isSnoob(j, i)

// Число тестовых запусков = 5
// Среднее время = 3,564 секунд
```

## Преобразование десятичного числа в двоичное

**Алгоритм:**

Мы переводим числа с основанием 10 в числа с основанием 2.
В этих двух системах счисления процедура счета различается главным образом из-за используемых символов.

Сначала опишем алгоритм конвертации:

1. Начиная с заданного числа, составить последовательность чисел таким образом, чтобы последующее число было половиной предыдущего,
   отбрасывая десятичную часть. Продолжить до тех пор, пока последний элемент не будет удовлетворять условию 2 > x > 0,
   где x — последнее число в последовательности.
   Формально S = {\\(x\_{1}\\), \\(x\_{2}\\),..., \\(x\_{n}\\)},
   где \\(x\_{2}\\) = \\(x\_{1}\\)/2, \\(x\_{3}\\) = \\(x\_{2}\\)/2 и т.д., и 2 > \\(x\_{n}\\) > 0.
2. Для каждого числа из приведенного выше списка разделить на 2 и хранить остаток в контейнере.
3. Теперь контейнер содержит двоичные эквивалентные биты в обратном порядке, \\(b\_{1}b\_{2}...b\_{n}\\),
   поэтому надо изменить порядок, чтобы получить двоичное эквивалентное число, \\(b\_{n}...b\_{2}b\_{1}\\).

**Оценка:**

- **Время** - ???
- **Память** - ???

**Код:**

```dotty
def decToBinConv(x: Int): String =
  val seqOfDivByTwo = Iterator.iterate(x)(a => a / 2)
  val binList = seqOfDivByTwo
    .takeWhile(a => a > 0)
    .map(a => a % 2)
  binList.mkString.reverse

decToBinConv(8) // "1000"
decToBinConv(7) // "111"  
```

**Метрики:**

Преобразование из десятичного в двоичный формат для первого миллиона чисел занимает 2 секунды.

```dotty
@main def decToBinConvBench(): Unit =
  (1 to 1_000_000).foreach: i =>
    decToBinConv(i)

// CPU Time: 1905 ms
// Allocation memory size: 1,59 GB      
```

**Код:**

```dotty
def isPalindrome(number: Long): Boolean = isPalindrome(number, 10)

// Является ли заданное число палиндромом в системе исчисления по заданному состоянию
def isPalindrome(number: Long, base: Int): Boolean =
  number == 0 || number > 0 && number % base != 0 && {
    var revertedNumber = 0L
    var k              = number
    while k > revertedNumber
    do
      revertedNumber = revertedNumber * base + k % base
      k /= base
    k == revertedNumber || k == revertedNumber / base
  }
```

**Метрики:**

Количество палиндромов в первом миллионе чисел (1998) рассчитывается меньше секунды.

```dotty
@main def isPalindromeBench(): Unit =
  println((1 to 1000000).count(isPalindrome))
      
// CPU Time: 312 ms
// Allocation memory size: 24,15 MB      
```
