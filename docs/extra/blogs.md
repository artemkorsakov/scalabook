# Блоги, подкасты, конференции

**Раздел "Блоги, подкасты, конференции"** предлагает доступ к разнообразным источникам информации, связанным с миром программирования.
Этот раздел включает три основных категории: **блоги**, **подкасты** и **конференции**.

## Подразделы

### Блоги

В этой части раздела представлен список популярных блогов по программированию. Блоги сортируются по нескольким критериям:

- **Количество RSS-подписчиков**
- **Дата последнего сообщения**
- **Алфавитный порядок**

### Подкасты

Для тех, кто предпочитает аудиоформат, собран список подкастов, посвящённых программированию.
Эти подкасты позволяют узнавать новое: интервью с ведущими специалистами отрасли,
обсуждения актуальных тем и обзоры новых инструментов и технологий.
Список подкастов организован в **алфавитном порядке**.

### Конференции

Здесь вы найдёте календарь мероприятий, таких как хакатоны, митапы и крупные международные события.
Список конференций отсортирован **по дате проведения**, начиная с ближайших событий.
