# Dequeue

_A deque_ or _double-ended queue_ is a linear list
in which all insertion and deletion operations (and, typically, data access operations) are performed at both ends of the list.

A deque is a more general variant of a stack or queue.
Additionally, one should distinguish between _output-restricted deques_
and _input-restricted deques_,
in which deletion and insertion operations respectively are performed only at one end.

When working with deques, the concepts of _left_ and _right_ ends are used.
