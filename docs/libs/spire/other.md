# Разное

Кроме того, Spire предоставляет множество других методов, которые "отсутствуют" в `java.Math` (и `scala.math`), 
например:

- `log(BigDecimal): BigDecimal`
- `exp(BigDecimal): BigDecimal`
- `pow(BigDecimal): BigDecimal`
- `pow(Long): Long`
- `gcd(Long, Long): Long`
- и так далее...
