# Сортировка слиянием

**Алгоритм:**

[Алгоритм сортировки слиянием](https://ru.wikipedia.org/wiki/%D0%A1%D0%BE%D1%80%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%BA%D0%B0_%D1%81%D0%BB%D0%B8%D1%8F%D0%BD%D0%B8%D0%B5%D0%BC) выглядят так:

- сортируемый массив разбивается на две части примерно одинакового размера
- каждая из получившихся частей сортируется отдельно, например — тем же самым алгоритмом
- два упорядоченных массива половинного размера соединяются в один

**Оценка:**

- **Время**:
  - Худшее - \\(O(n log(n))\\)
  - Лучшее - \\(O(n log(n))\\)
  - Среднее - \\(O(n log(n))\\)
- **Память** - \\(O(1)\\) для списка, \\(O(n)\\) для массива

**Код и Пояснение:**

Отличие от императивной реализации по умолчанию — это способ разделения списка на две части. 
Обычно это решается использованием длины списка, стоимость которой составляет O(n), 
поскольку требуется пройти от начала до конца. 
[В этой реализации](https://github.com/vkostyukov/scalacaster/blob/master/src/sort/MergeSort.scala) 
список разбивается на две равные части с помощью функции `halve`. 
Эта функция выполняет простую вещь — она берет первые два элемента списка 
и добавляет их в два отдельных списка, которые накапливают результат. 
Другими словами, функция добавляет все четные узлы в первую часть, 
а нечетные — во вторую. Это можно сделать за O(n).


- Входные данные: Метод `mergeSort` принимает список элементов типа A, для которых определен порядок (сравнение).
- Разделение списка: Внутренний метод `halve` разделяет входной список на две части. 
  Он использует вспомогательную рекурсивную функцию `loop`, которая принимает три параметра: текущий список, список для первой половины и список для второй половины.
  `loop` проходит по элементам списка, добавляя их поочередно в первую и вторую половины, пока не обработает все элементы.
  В результате `halve` возвращает кортеж из двух списков: первой и второй половин.
- Сортировка половин: Внутренний метод `halveAndSort` вызывает `halve` для разделения списка, а затем рекурсивно вызывает `sort` для сортировки каждой из половин.
  Метод `sort` принимает кортеж из двух списков и сортирует их. Если оба списка пусты, он возвращает пустой список. 
  Если один из списков содержит один элемент, он возвращает этот элемент в виде списка. Если оба списка содержат элементы, они сортируются.
- Слияние отсортированных половин: Метод `merge` принимает два отсортированных списка и объединяет их в один отсортированный список. 
  Он использует рекурсивную функцию `loop`, которая сравнивает элементы из двух списков.
  `loop` добавляет меньший элемент из двух списков в результирующий список, пока один из списков не станет пустым. 
  После этого оставшиеся элементы другого списка добавляются в результат.
- Обратный порядок: Результат слияния собирается в обратном порядке, 
  поэтому в конце `loop` вызывается `reverse`, чтобы вернуть элементы в правильном порядке.
- Возврат результата: Метод `mergeSort` возвращает окончательно отсортированный список.

```dotty
def mergeSort[A: Ordering](list: List[A]): List[A] =
  def halveAndSort(as: List[A]) = sort(halve(as))

  def sort(p: (List[A], List[A])): List[A] = p match
    case (Nil, Nil)       => Nil
    case (ha :: Nil, Nil) => ha :: Nil
    case (Nil, hb :: Nil) => hb :: Nil
    case (as, bs)         => merge(halveAndSort(as), halveAndSort(bs))

  def halve(as: List[A]): (List[A], List[A]) =
    @tailrec
    def loop(bs: List[A], fs: List[A], ss: List[A]): (List[A], List[A]) =
      bs match
        case f :: s :: r => loop(r, f :: fs, s :: ss)
        case f :: Nil    => (f :: fs, ss)
        case Nil         => (fs, ss)

    loop(as, Nil, Nil)

  def merge(as: List[A], bs: List[A]): List[A] =
    @tailrec
    def loop(cs: List[A], ds: List[A], r: List[A]): List[A] = (cs, ds) match
      case (Nil, Nil) => r.reverse
      case (_, Nil)   => r.reverse ++ cs
      case (Nil, _)   => r.reverse ++ ds
      case (ha :: ta, hb :: tb) =>
        if ha < hb then loop(ta, ds, ha :: r)
        else loop(cs, tb, hb :: r)

    loop(as, bs, Nil)

  halveAndSort(list)
end mergeSort

mergeSort(List(3, 1, 4, 2))
// List(1, 2, 3, 4)
```
