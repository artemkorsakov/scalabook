# Теория чисел

## Введение

Алгоритмы, основанные на теории чисел, представляют собой важную категорию алгоритмов, 
которые используются для решения различных задач, связанных с целыми числами. 
Эти алгоритмы находят применение в криптографии, теории чисел, комбинаторике и других областях. 
Вот несколько ключевых алгоритмов, основанных на теории чисел:

## Примеры алгоритмов

### Алгоритм Евклида

Алгоритм Евклида используется для нахождения наибольшего общего делителя (НОД) двух целых чисел. 
Он основан на свойствах делимости и работает по принципу рекурсивного деления.

```dotty
@annotation.tailrec
final def gcd(a: Long, b: Long): Long =
  if b == 0 then a
  else gcd(b, a % b)

gcd(4851, 3003)
// 231  
```

### Расширенный алгоритм Евклида

Этот алгоритм не только находит НОД двух чисел, 
но и позволяет выразить его в виде линейной комбинации этих чисел \\(x \times a + y \times b = d\\). 
Это полезно для решения диофантовых уравнений.

```dotty
def extendedGcd(a: Long, b: Long): (Long, Long, Long) =
    if b == 0 then
      (a, 1, 0)
    else
      val  (gcd, x1, y1) = extendedGcd(b, a % b)
      val x = y1
      val y = x1 - (a / b) * y1
      (gcd, x, y)

extendedGcd(17, 5)
// (1,-2,7)   
// -2*17 + 7*5 = 1
```

### Алгоритм факторизации

Факторизация — это процесс разложения числа на произведение простых множителей. 
Существует несколько алгоритмов для факторизации, включая:

- **Алгоритм пробного деления**: Проверяет делимость числа на все простые числа до его квадратного корня.
- **Алгоритм Ферма**: Использует разность квадратов для нахождения делителей.
- **Алгоритм квадратичного решета**: Более сложный и эффективный метод для факторизации больших чисел.

### Алгоритм Миллера-Рабина

[Алгоритм Миллера-Рабина][miller] - вероятностный тест простоты, 
который позволяет определить, является ли число простым. 
Он основан на свойствах чисел в модульной арифметике и используется в криптографии.

### Алгоритм китайской теоремы об остатках

[Китайская теорема об остатках][china] позволяет решать системы линейных сравнений с различными модулями. 
Алгоритм используется для нахождения единственного решения в пределах произведения модулей.

## Заключение

Алгоритмы, основанные на теории чисел, играют ключевую роль в различных областях математики и информатики. 
Они позволяют решать задачи, связанные с делимостью, простотой чисел, факторизацией и многими другими аспектами, 
что делает их незаменимыми в криптографии, численных методах и теории чисел.
