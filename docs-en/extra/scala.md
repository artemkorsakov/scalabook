# Scala Resources

A curated collection of resources for learning and working with Scala. All resources are organized by category and sorted for easy navigation.

## Resource Categories

### Books

- Comprehensive guides to the Scala language
- From basic syntax to advanced topics:
    - Functional programming
    - Collections
    - Concurrency
    - Code optimization

### Courses

- Online courses for all skill levels
- Interactive learning programs
- Webinars with hands-on exercises

### Practice

- Exercises to reinforce your knowledge:
    - Simple tasks for beginners
    - Complex challenges for experienced developers
    - Real-world examples

### Articles and Blogs

- Technical articles and guides
- Library usage examples
- New language feature deep-dives
- Development best practices

### Videos

- Conference and meetup recordings
- Video tutorials on various Scala aspects
- Screencasts and live coding sessions

## Sorting System

Resources are organized according to the following scheme:

- By Scala version:
    - Scala 3 + version-independent
    - Scala 2
- By language:
    - English
    - Russian
- Alphabetically within each category
