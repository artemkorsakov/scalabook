# Домашняя

В этой рабочей тетради собрана информация, в основном посвященная функциональной разработке на Scala.

Рабочая тетрадь состоит из следующих разделов, доступных для выбора в верхнем меню:

- [Блог](https://scalabook.ru/blog) - статьи и выступления на митапах.
- [Обзор Scala](https://scalabook.ru/scala) - описание языка Scala.
- [Функциональное программирование](https://scalabook.ru/fp) - раздел о функциональном программировании.
- [Теория категорий](https://scalabook.ru/typeclass) - классы типов и теория категорий в Scala.
- [Структуры данных и алгоритмы](https://scalabook.ru/algorithms) - алгоритмы и основные структуры данных в Scala.
- [Scala библиотеки](https://scalabook.ru/libs) - раздел о Scala библиотеках.
- [Паттерны проектирования](https://scalabook.ru/patterns) - паттерны проектирования на Scala.
- [Упражнения из книг](https://scalabook.ru/books) - упражнения из книг, разобранные на Scala.
- [Ресурсы для обучения](https://scalabook.ru/extra) - 
  дополнительные материалы и ресурсы для обучения (книги, статьи, курсы, видео и т.п.)
