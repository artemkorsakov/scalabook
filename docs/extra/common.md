# Ресурсы по программированию

Структурированная база материалов для изучения программирования в целом. 

## Категории

### Книги

- Фундаментальные труды и современные издания
- Темы:
    - Основы программирования
    - Алгоритмы и структуры данных
    - Архитектура ПО
    - Принципы разработки
    - Специализированные технологии

### Курсы

- Онлайн-обучение с практикой
    - Для начинающих
    - Продвинутые программы
    - Специализированные направления
    - Сертифицированные курсы

### Практика

Раздел с практическими заданиями и упражнениями, которые позволят закрепить полученные знания. 
Выполнение упражнений поможет лучше понять принципы работы кода и улучшить навыки программирования.

### Статьи

Подборка статей из области программирования. 
В статьях рассматриваются различные аспекты разработки программного обеспечения и обсуждаются лучшие практики.

### Видео

- Обучающий и аналитический контент:
    - Лекции экспертов
    - Доклады с конференций
    - Разборы архитектур
    - Live-сессии кодинга

## Система сортировки

Материалы организованы по следующей схеме:

- По языку контента:
    - На русском
    - На английском
- В алфавитном порядке внутри категорий
