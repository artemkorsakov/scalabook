# Обзор Algebra

**Algebra** — это библиотека (или модуль в составе Cats), 
которая использует **классы типов** для представления **алгебраических структур**. 
Простыми словами, она позволяет вам описывать формальные математические свойства, 
которыми должны обладать типы данных в вашей программе.

Вы можете использовать эти классы типов, чтобы выразить **абстрактные возможности** (и требования), 
которыми должны обладать обобщённые параметры (дженерики). 
Вместо того чтобы привязываться к конкретному типу вроде `Int` или `String`, 
вы пишете код, работающий с любым типом `A`, который умеет «складываться» (имеет `Semigroup`) или «обнуляться» (имеет `Monoid`).

**Аналогия из жизни:**  

Представьте, что вы пишете функцию, которая складывает список элементов. 
Вам не важно, что это за элементы — числа, строки или списки. 
Главное, чтобы для них была определена операция «сложения» (объединения). 
Algebra позволяет выразить это требование в коде.

## Раздел 1: Алгебраические свойства и терминология

В этом разделе объясняются базовые математические свойства, которыми могут обладать операции. 
Понимание этих терминов критически важно для работы с библиотекой.

Вот таблица, переписанная в указанном формате:

- **Ассоциативность**:
    - Описание: Результат не зависит от порядка вычислений (расстановки скобок).
    - Формула: `a ⊕ (b ⊕ c) = (a ⊕ b) ⊕ c`
    - Пример на целых числах: `(2 + 3) + 4 = 2 + (3 + 4) = 9`
- **Коммутативность**:
    - Описание: Результат не зависит от порядка аргументов.
    - Формула: `a ⊕ b = b ⊕ a`
    - Пример на целых числах: `2 + 3 = 3 + 2 = 5` (но вычитание — нет!)
- **Нейтральный элемент (Identity)**:
    - Описание: Существует элемент, который при операции с любым другим даёт этот другой.
    - Формула: `a ⊕ id = id ⊕ a = a`
    - Пример на целых числах: Для сложения это `0` (`5 + 0 = 5`). Для умножения — `1`.
- **Обратный элемент (Inverse)**:
    - Описание: Для каждого элемента существует парный, который в сумме даёт нейтральный.
    - Формула: `a ⊕ ¬a = ¬a ⊕ a = id`
    - Пример на целых числах: Для `5` обратный по сложению — `-5` (`5 + (-5) = 0`).
- **Дистрибутивность**:
    - Описание: Правило «раскрытия скобок» для двух операций.
    - Формула: `a ⊙ (b ⊕ c) = (a ⊙ b) ⊕ (a ⊙ c)`
    - Пример на целых числах: Умножение дистрибутивно относительно сложения: `2 * (3 + 4) = (2*3) + (2*4)`.
- **Идемпотентность**:
    - Описание: Применение операции дважды равно одному применению.
    - Формула: `a ⊕ a = a`
    - Пример на целых числах: Для операции `max`: `max(5,5) = 5`. Для функции: `abs(abs(x)) = abs(x)`.

### Важное замечание о нотации

Хотя эти свойства описаны с помощью символов (`⊕`, `⊙`), они работают и с обычными функциями:

- Когда вы видите `a ⊕ b`, это эквивалентно вызову бинарной функции `f(a, b)`. Символ `⊕` — это просто удобная инфиксная запись.
- Когда вы видите `¬a`, это эквивалентно вызову унарной функции `g(a)` (например, `-a`).

## Раздел 2: Базовые алгебраические структуры

Эти структуры находятся в пакете `algebra`. 
Все они реализуют метод **`combine`** (комбинировать), который **всегда ассоциативен**.

- Если есть **нейтральный элемент**, он называется **`empty`**.
- Если есть **обратный элемент**, он называется **`inverse`**.

## Описание структур (столбец «Что означает / Пример»)

- [**Semigroup**](../../typeclass/monoid/semigroup.md): Самая простая структура: умеет только объединять.  
  *Пример: объединение строк ("a" + "b") или списков.*
- [**CommutativeSemigroup**](../../typeclass/monoid/csemigroup.md): Объединение не зависит от порядка.  
  *Пример: сложение целых чисел (2+3 = 3+2), но не объединение строк.*
- [**Monoid**](../../typeclass/monoid/monoid.md): Умеет объединять и имеет «пустое» значение.  
  *Пример: списки (пустой список), строки (пустая строка), сложение чисел (0).*
- [**Band**](../../typeclass/monoid/band.md): Каждый элемент идемпотентен относительно `combine`.  
  *Пример: операция `min` или `max` (min(5,5) = 5).*
- [**Semilattice**](../../typeclass/monoid/semilattice.md): Коммутативная версия Band.  
  *Пример: пересечение множеств (идемпотентно и коммутативно).*
- [**Group**](../../typeclass/monoid/group.md): Полноценная группа: есть сложение, ноль и вычитание.  
  *Пример: целые числа с операцией + (есть 0 и -a).*
- [**CommutativeMonoid**](../../typeclass/monoid/cmonoid.md): Коммутативный моноид.  
  *Пример: умножение положительных чисел (порядок не важен, есть 1).*
- [**CommutativeGroup**](../../typeclass/monoid/abgroup.md): Абелева группа.  
  *Пример: сложение целых чисел (есть 0, есть -a, и 2+3 = 3+2).*
- [**BoundedSemilattice**](../../typeclass/monoid/bounded-semilattice.md): Полурешётка с границей (нейтральным элементом).  
  *Пример: для операции `min` нейтральным элементом будет +∞ (максимальное значение).*

## Раздел 3: Кольцеподобные структуры (Ring-like)

Пакет `algebra.ring` содержит более сложные структуры, сочетающие **две операции**:

1. **Аддитивная** (сложение): называется **`plus`**.
2. **Мультипликативная** (умножение): называется **`times`**.

**Общие правила для всех кольцеподобных структур:**

- Обе операции (`+` и `*`) **ассоциативны**.
- Сложение (`+`) **коммутативно**.
- Всегда есть **`zero`** (нейтральный элемент для сложения, аналог `0`).

### Описание структур (столбец «Краткое описание»)

- [**Semiring**](../../typeclass/monoid/semiring.md): Полукольцо. 
  Умеет складывать и умножать, но нет вычитания (`negate`) и нет обязательной единицы (`1`).  
  *Пример: натуральные числа (без нуля?).*
- [**Rng**](../../typeclass/monoid/rng.md) (Ring without 'i' - identity): Кольцо без единицы (пропущена буква 'i' в слове Ring).  
  *Пример: чётные целые числа (умножение есть, единицы '1' нет).*
- [**Rig**](../../typeclass/monoid/rig.md) (Ring without 'n' - negative): Кольцо без «негатива» (нет вычитания, но есть умножение и 1).  
  *Пример: натуральные числа с 0 и 1.*
- [**CommutativeSemiring**](../../typeclass/monoid/csemiring.md): Коммутативное полукольцо (умножение не зависит от порядка).
- [**CommutativeRig**](../../typeclass/monoid/rig.md): Коммутативное Rig (умножение не зависит от порядка).
- [**Ring**](../../typeclass/monoid/ring.md): Полноценное кольцо: есть сложение, вычитание, умножение и единица.  
  *Пример: целые числа (`Int`).*
- [**CommutativeRing**](../../typeclass/monoid/cring.md): Коммутативное кольцо.  
  *Пример: целые числа (3*4 = 4*3).*
- [**Semifield**](../../typeclass/monoid/field.md): Полуполе: есть умножение, единица и обратное (деление), но нет вычитания.
- [**CommutativeSemifield**](../../typeclass/monoid/field.md): Коммутативное полуполе.
- [**Field**](../../typeclass/monoid/field.md): **Поле**. Есть всё: сложение, вычитание, умножение, деление (кроме деления на ноль).  
  *Пример: рациональные числа, вещественные числа (Double с осторожностью).*

## Раздел 4: Решёткоподобные структуры (Lattice-like)

Пакет `algebra.lattice` представляет структуры, которые могут напоминать кольца, но работают по другим законам.

Вместо `plus` (сложение) и `times` (умножение) здесь используются:

- **`meet`** (встреча) — аналог логического **И** (AND) или операции взятия **минимума** («наибольшая нижняя граница»).
- **`join`** (объединение) — аналог логического **ИЛИ** (OR) или операции взятия **максимума** («наименьшая верхняя граница»).

**Свойства `meet` и `join`:**

- Они всегда ассоциативны, коммутативны и идемпотентны (`a ∧ a = a`).
- Каждый по отдельности образует **полурешётку** (Semilattice).

**Дополнительные элементы:**

- **`zero`**: если есть, то `join(a, zero) = a` (ноль — нижняя граница, объединение с ним не меняет элемент).
- **`one`**: если есть, то `meet(a, one) = a` (единица — верхняя граница).
- **Закон поглощения (Absorption)**: если есть оба, то `meet(a, join(a, b)) = join(a, meet(a, b)) = a`.
- **Дистрибутивность**: `meet` дистрибутивен относительно `join` и наоборот.
- **`imp` (импликация)**: специальная операция, означающая «если... то...».

### Таблица решёткоподобных структур

- **JoinSemilattice**: Полурешётка объединения (умеет только `join`).
- **MeetSemilattice**: Полурешётка пересечения (умеет только `meet`).
- **BoundedJoinSemilattice**: Полурешётка объединения с нулём (нижней границей).
- **BoundedMeetSemilattice**: Полурешётка пересечения с единицей (верхней границей).
- **Lattice**: Полная решётка (есть и встреча, и объединение).
- **DistributiveLattice**: Дистрибутивная решётка.  
  *Пример: множества с `∩` и `∪`.*
- **BoundedLattice**: Решётка с границами (есть и 0, и 1).
- **BoundedDistributiveLattice**: Дистрибутивная решётка с границами.
- **Heyting**: **Алгебра Гейтинга**. Решётка с импликацией.  
  *Пример: логика без закона исключённого третьего.*
- **Bool**: **Булева алгебра**. Классическая логика с законом исключённого третьего (`a || !a == true`).  
  *Пример: `true/false`, битовые маски.*

### Важные связи между структурами

1. **Связь с кольцами:** `BoundedDistributiveLattice` (ограниченная дистрибутивная решётка) даёт вам `CommutativeRig` 
   (коммутативное полукольцо), но **не наоборот**. В полукольцах нет дистрибутивности `+` относительно `*` в том виде, 
   как она определена для решёток.
2. **Bool и кольца:** Булева алгебра (`Bool`) порождает **кольцо Буля** (`BoolRing`), 
   где каждый элемент является своим собственным отрицанием. 
   Однако обратите внимание: метод `.asBoolRing` **не является** расширением метода `.asCommutativeRig`, 
   потому что операция `plus` (сложение) в кольце Буля определяется иначе (как XOR), а не как `join` (OR).
