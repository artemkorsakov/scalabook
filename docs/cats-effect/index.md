# Cats effect

[**Cats Effect**][home] — это чистая асинхронная среда выполнения для Scala. 
Она даёт отличные возможности для написания высоконадёжных, быстрых и параллельных программ, 
оставаясь при этом верной принципам функционального программирования.

## Ключевые возможности

### **Асинхронность** (asynchronous)

Монада `IO` позволяет захватывать и контролировать асинхронные эффекты, управляемые обратными вызовами (callback), 
за чистым синхронным интерфейсом. 
Хотя внешне она похожа на `Future`, `IO` выводит эту концепцию на новый уровень, 
давая полный контроль над семантикой и поведением вычислений. 
Пишите программы, которые бесшовно смешивают синхронный и асинхронный код без ущерба для понимания и композиции.

### **Одновременность** (concurrent)

`IO` может обеспечивать высокопараллельные приложения, например, веб-сервисы, обрабатывающие десятки тысяч запросов в секунду.
Одновременность в `IO` реализована через волокна (fibers) — легковесные, прерываемые потоки, полностью управляемые средой выполнения. 
Волокна гораздо дешевле нативных потоков ОС, поэтому ваше приложение может запускать десятки миллионов волокон без особых усилий.

### **Трассировка**

`IO` собирает информацию во время выполнения программы, что позволяет легко отследить источник ошибок 
или исследовать программу по ходу её работы. 
Трассировку можно включить в продакшене без заметного влияния на производительность, 
что автоматически открывает мощные возможности, такие как расширенные исключения, упрощающие диагностику ошибок.

### **Безопасность**

Приложения реального мира часто работают с ресурсами: сетевыми соединениями, файловыми дескрипторами. 
Управление ресурсами — исключительно сложная задача в параллельных приложениях. 
Одна небольшая ошибка может привести к утечке памяти или даже дедлоку. 
`IO` управляет жизненным циклом ресурсов, гарантируя их безопасное выделение 
и освобождение даже при возникновении исключений и отмен.

### **Композируемость**

Cats Effect следует принципам чисто функционального программирования: 
`IO` представляет собой _описание_ программы, а не запущенное вычисление. 
Это даёт вам полный контроль над тем, как и когда вычисляются эффекты. 
Из простых программ можно составлять более сложные, сохраняя способность рассуждать о поведении и сложности. 
Рефакторинг без страха!

### **Мощное абстрактное исчисление**

Cats Effect уникальным образом определяет, что значит быть функциональным эффектом. 
Это даёт ему непревзойдённую выразительную и композиционную силу, открывая целую экосистему расширяемости. 
Вы получаете возможность переопределять саму среду выполнения, 
привнося полную мощь экосистемы Cats для элегантного решения сложных задач: 
распределённой трассировки, внедрения зависимостей, отправки ошибок по нескольким каналам и многого другого!

Система абстракций Cats Effect — это результат многолетних исследований и опыта 
в области применения концепций функционального программирования в реальных приложениях на JVM и JavaScript.

## Введение в библиотеку Cats Effect

### 1. Подключение зависимости

Для начала работы с **Cats Effect** необходимо добавить её в файл сборки `build.sbt`.

```sbt
libraryDependencies += "org.typelevel" %% "cats-effect" % "3.7.0"
```

**Что это даёт?**

- `IO` — основной тип данных, представляющий _описание_ эффекта ввода-вывода.
- `IOApp` — абстракция для создания безопасных, управляемых приложений с корректной обработкой ресурсов и завершения.
- Возможность создавать одновременные, параллельные, асинхронные программы без низкоуровневых проблем с потоками.

### 2. Простейшее приложение на Cats Effect

Создайте файл `HelloWorld.scala` со следующим содержимым:

```dotty
import cats.effect.{IO, IOApp}

object HelloWorld extends IOApp.Simple:
  val run: IO[Unit] = IO.println("Hello, World!")
```

**Пояснение:**

- `IOApp.Simple` — удобный трейт, требующий реализовать только метод `run: IO[Unit]`.
- `IO.println("Hello, World!")` — не выполняет печать немедленно, а _описывает_ действие, которое будет выполнено при запуске.
- Вся программа — это **чистое значение** типа `IO[Unit]`, которое можно передавать, комбинировать и повторно использовать.

**Запуск:**

```bash
sbt run
```

Вы увидите:

```
Hello, World!
```

### 3. Возможности полноценного приложения

Приложения, построенные на `IOApp`, автоматически получают:

- **Таймеры** (`sleep`, `timeout`, `clock`) — через `cats.effect.Temporal`.
- **Многопоточность** — через `cats.effect.Async` и `cat.effect.std`.
- **Одновременность** — лёгкие _волокна_ (fibers), аналогичные виртуальным потокам, но гораздо легче потоков ОС.
- **Структурированную одновременность** — автоматическое управление временем жизни дочерних волокон.
- **Отменяемость** и устойчивость к ошибкам.

### 4. Пример: FizzBuzz с четырьмя параллельными волокнами

Этот пример демонстрирует, как легко описать параллельную программу на Cats Effect. 
Четыре волокна работают параллельно:

```dotty
import cats.effect.{IO, IOApp}
import scala.concurrent.duration.*

object StupidFizzBuzz extends IOApp.Simple:
  val run: IO[Unit] =
    for
      ctr <- IO.ref(0)           // 1. Создаём атомарный счётчик

      wait = IO.sleep(1.second)  // 2. Программа ожидания
      poll = wait *> ctr.get     // 3. Опрос: ждём, затем читаем значение

      // Волокно 1: выводит только число
      _ <- poll.flatMap(IO.println(_)).foreverM.start

      // Волокно 2: выводит "fizz" если число кратно 3
      _ <- poll.map(_ % 3 == 0)
               .ifM(IO.println("fizz"), IO.unit)
               .foreverM.start

      // Волокно 3: выводит "buzz" если число кратно 5
      _ <- poll.map(_ % 5 == 0)
               .ifM(IO.println("buzz"), IO.unit)
               .foreverM.start

      // Волокно 4: увеличивает счётчик каждую секунду
      _ <- (wait *> ctr.update(_ + 1)).foreverM.void
    yield ()   
```

**Разбор ключевых конструкций:**

| Конструкция     | Значение                                                              |
|-----------------|-----------------------------------------------------------------------|
| `IO.ref(0)`     | Создаёт потокобезопасную ссылку на изменяемое значение.               |
| `*> (productR)` | Выполняет левое действие, затем правое, возвращая результат правого.  |
| `foreverM`      | Повторяет действие бесконечно.                                        |
| `.start`        | Запускает действие в отдельном волокне и сразу возвращает управление. |
| `void`          | Игнорирует результат действия.                                        |

**Пример вывода (фрагмент):**

```text
0
buzz
fizz
2
fizz
3
4
buzz
5
fizz
6
7
8
fizz
9
buzz
10
```

**Обратите внимание на важный момент:**  

Переменные `wait` и `poll` — это _значения_ `IO`. 
Они используются в четырёх независимых волокнах, но их поведение остаётся одинаковым. 
Это возможно потому, что мы работаем с _описаниями вычислений_, а не с самими вычислениями.

- **Композиция** — простые программы (`wait`, `poll`) легко комбинируются в сложные.
- **Повторное использование** — одно и то же описание используется многократно без неожиданных побочных эффектов.
- **Параллелизм без боли** — запуск четырёх независимых волокон требует всего нескольких вызовов `.start`.
- **Безопасность** — Cats Effect автоматически управляет отменой и финализацией ресурсов.

> **Терминология:**  
> Cats Effect использует понятие _волокно (fiber)_ — легковесный поток, который планируется на потоке JVM. 
> Можно создать тысячи и даже миллионы волокон без проблем.

## Заключение

Cats Effect предлагает выразительный и безопасный способ построения параллельных систем на Scala. Ключевые идеи:

- **Описание, а не выполнение** — `IO` описывает действие, выполнение происходит только через рантайм.
- **Композиция** — маленькие программы легко объединяются в большие.
- **Структурированная одновременность** — волокна управляются автоматически, утечки ресурсов невозможны.
