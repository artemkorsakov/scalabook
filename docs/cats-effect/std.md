# Стандартная библиотека

Этот раздел — коллекция **мощных, готовых к использованию конкурентных примитивов**. 
Они строятся на основе базовых типов (`Ref`, `Deferred`) и 
решают типовые задачи многопоточного программирования в функциональном стиле.

| Категория                 | Примитивы и их суть                                                                                                                                                                                 |
|:--------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Безопасное состояние**  | **`Ref` / `AtomicCell` / `MapRef`**: Атомарные ссылки для конкурентного доступа к данным (от одного значения до целых `Map`).                                                                       |
| **Асинхронные очереди**   | **`Queue`, `Dequeue`, `Priority Queue`**: Потокобезопасные очереди для обмена данными между волокнами (FIFO, двусторонние, с приоритетом).                                                          |
| **Синхронизация**         | **`Semaphore`, `Mutex`, `CountDownLatch`, `CyclicBarrier`**: Классические примитивы для контроля параллелизма: ограничение доступа, взаимное исключение, ожидание сигналов от группы волокон.       |
| **Жизненный цикл**        | **`Resource`**: Фундаментальный блок для безопасного управления ресурсами (файлы, соединения), гарантирующий их закрытие.                                                                           |
| **Управление волокнами**  | **`Supervisor`**, **`Hotswap`**: `Supervisor` наблюдает за дочерними волокнами и отменяет их при ошибке. `Hotswap` позволяет атомарно заменять активный ресурс.                                     |
| **Интеграция с IO**       | **`Dispatcher`**: Мост из мира `IO` в императивный код (например, для колбэков из Java-библиотек).                                                                                                  |
| **Ввод/вывод, окружение** | **`Console`, `Env`, `Random`**: Типобезопасные, эффектные обёртки для операций ввода-вывода, чтения переменных окружения и генерации случайных чисел.                                               |
| **Экспериментальное**     | **`Async/Await`**: Предоставляет синтаксис, похожий на `async/await` из других языков (может измениться в будущем).                                                                                 |
| **Утилиты**               | **`Backpressure`**: Помогает контролировать скорость обработки данных, избегая переполнения систем.                                                                                                 |

### Пример одного примитива: `CountDownLatch`

Как видно из документации по вашей ссылке, `CountDownLatch` работает просто:

```dotty
import cats.effect.IO
import cats.effect.std.CountDownLatch

val program: IO[Unit] =
  for
    latch <- CountDownLatch[IO](2) // 1. Создаём защёлку на 2 события
    _ <- (latch.await >> IO.println("Разблокировано!")).start // 2. Волокно ждёт
    _ <- IO.println("Первый сигнал") >> latch.release         // 3. Сигнал 1
    _ <- IO.println("Второй сигнал") >> latch.release         // 4. Сигнал 2
  // После двух сигналов awaiting волокно печатает "Разблокировано!"
  yield ()
```

**Ключевые особенности стандартной библиотеки Cats Effect:**

- **Все примитивы являются отменяемыми** (cancelable) и корректно работают с волокнами.
- **Неблокирующие** — используют семантическую блокировку, не останавливая системные потоки.
- **Композиционные** — легко комбинируются друг с другом для сложной логики.
