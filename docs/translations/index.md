# Переводы

Этот раздел посвящён переводам на русский язык статей, учебных материалов и докладов по функциональному программированию на Scala. 
Здесь собраны ключевые работы от авторитетных авторов, охватывающие темы:

- Основы ФП (монады, функторы, аппликативы)
- Практическое применение Scala (ZIO, Cats Effect, fs2)
- Оптимизация и архитектура приложений
- Новые возможности языка и экосистемы

Цель — сделать качественные материалы доступными для русскоязычной аудитории, сохраняя точность терминологии и смысла оригиналов.
