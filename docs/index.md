# Scalabook

Документация по функциональному программированию на Scala, организованная как open-source knowledge base.

## О проекте

Это:

- Рабочая тетрадь с постоянно обновляемыми конспектами
- Коллекция концепций FP
- Практические материалы для углубленного изучения Scala
- Open-source knowledge base

## Основные разделы

| Раздел                                               | Описание                                                                                  |
|------------------------------------------------------|-------------------------------------------------------------------------------------------|
| [Функциональное программирование](fp/index.md)       | Основные концепции и принципы функционального программирования                            |
| [Типовые классы](typeclass/index.md)                 | Изучение типовых классов и теории категорий                                               |
| [Алгоритмы и структуры данных](algorithms/index.md)  | Реализация классических алгоритмов и структур данных в функциональном стиле               |
| [Scala библиотеки](libs/index.md)                    | Обзор популярных библиотек для функционального программирования на Scala                  |
| [Упражнения из книг](books/index.md)                 | Практические задания из различных книг и сайтов с упражнениями                            |
| [Ресурсы для обучения](extra/index.md)               | Полезные ссылки на книги, статьи, онлайн-курсы и видеоматериалы для углубленного изучения |
