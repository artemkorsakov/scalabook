# Hello, World!

В этом разделе мы рассмотрим классический пример программы на языке Scala, который выводит на экран фразу "Hello, world!". Этот пример является традиционным стартом для изучения любого нового языка программирования, так как он демонстрирует основные синтаксические конструкции и принципы работы с программой.

### Шаг 1: Создание файла

Первым делом вам нужно создать файл, в который вы поместите код вашей программы. Назовите этот файл `Hello.scala`. Расширение `.scala` указывает на то, что файл содержит код на языке Scala.

### Шаг 2: Написание кода

Внутри файла `Hello.scala` добавьте следующий код:

```dotty
@main def hello = println("Hello, world!")
```

В этом коде мы определяем метод `hello`, который будет являться точкой входа в нашу программу.

- **Метод `hello`**: Он объявлен с помощью ключевого слова `def`, что указывает на то, что это метод.
- **Аннотация `@main`**: Эта аннотация указывает компилятору, что данный метод является основным методом, который будет вызван при запуске программы. Это упрощает процесс создания исполняемых приложений на Scala, так как вам не нужно вручную указывать точку входа.
- **`println`**: Внутри метода мы используем функцию `println`, которая выводит текст на стандартный вывод (STDOUT). В данном случае мы передаем строку "Hello, world!", которая будет отображена на экране.

### Шаг 3: Компиляция кода

После того как вы написали код, следующим шагом будет его компиляция. Для этого откройте терминал и выполните следующую команду:

```
> scalac Hello.scala
```

Команда `scalac` — это компилятор Scala, который преобразует ваш исходный код в байт-код, который может быть выполнен виртуальной машиной Java (JVM). После успешной компиляции в текущем каталоге появятся файлы с расширением `.class`, которые содержат скомпилированный код.

### Шаг 4: Запуск программы

Теперь, когда ваш код скомпилирован, вы можете запустить его с помощью следующей команды:

```
> scala hello
```

Эта команда запускает вашу программу, и вы должны увидеть вывод:

```
Hello, world!
```

Таким образом, вы успешно написали, скомпилировали и запустили свою первую программу на языке Scala!
