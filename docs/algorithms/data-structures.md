# Структуры данных

Раздел представляет собой набор материалов, посвященных изучению и 
практическому применению различных структур данных на языке программирования Scala 3. 
В этом разделе рассматриваются основные структуры данных, их особенности, принципы работы, 
а также примеры их реализации на языке Scala 3.

В разделе представлены следующие темы:

- Основные структуры данных: массивы, списки, стеки, очереди, деревья, графы и другие.
- Особенности структур данных на языке Scala 3: использование функционального программирования, 
  паттерны, итераторы, генераторы и другие.
