# Тригонометрия

`Trig` предоставляет абстракцию для любого типа, определяющего тригонометрические функции. 
Для этого типы должны иметь возможность разумно аппроксимировать реальные значения.

- _Trig_
    - `e`: число Эйлера, `2.71828...`
    - `pi`: число Пи - отношение длины окружности к диаметру, `3.14159...`
    - `exp`: экспоненциальная функция, \\(e^{x}\\)
    - `expm1`: \\(e^{x} - 1\\)
    - `log`: натуральный логарифм
    - `log1p`: `log(x + 1)`
    - `sin`, `cos`, `tan`: синус, косинус и тангенс — стандартные функции углов
    - `asin`, `acos`, `atan`, `atan2`: обратные функции
    - `sinh`, `cosh`, `tanh`: гиперболические функции
    - `toRadians`, `toDegrees`: преобразование единиц измерения углов
