# Scalabook

[ScalaBook](https://scalabook.ru) — это постоянно обновляемая рабочая тетрадь по функциональному программированию на Scala,
охватывающая следующие темы:

- Основы функционального программирования
- Алгоритмы и структуры данных
- Классы типов и работа с типами в Scala
- Практические упражнения для закрепления материала

## Цель проекта

Практика показывает, что у Scala - высокий порог входа. Это цена за его выразительность, гибкость и мощь.
Но высокий порог входа - проблема ли это разработчиков, только начинающих изучать Scala и ФП?
Скорее это проблема тех, кто уже знает Scala, кто перепрыгнул через пропасть,
но не может или не хочет построить через эту пропасть мост.
А кричит следующему: "Прыгай и ты! Я же смог!"

**Цель ScalaBook** — построить "мост".
Высокий порог входа - это не повод для гордости "а я смог!",
а повод задуматься: а что ты сделал, чтобы этот порог снизить?
