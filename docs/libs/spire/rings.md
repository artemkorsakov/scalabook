# Ring и компания

Семейство классов типов `Ring` обеспечивает типичные арифметические операции, которые ожидают большинство пользователей.

- `Semiring`
    - `plus` (`+`): сложение
    - `times` (`*`): умножение
    - `pow` (`**`): возведения в степень (интегральная экспонента)
- `Rng`
    - `negate` (`-`): обратная операция сложению
    - `minus` (`-`): вычитание
    - `zero`: аддитивное тождество (такой элемент, что для любого `x` из множества `x + zero = x`)
- `Rig`
    - `zero`: аддитивное тождество
    - `one`: мультипликативное тождество (такой элемент, что для любого `x` из множества `x * one = x`)
- `Ring` (`Rng` + `Rig`)
- `GCDRing`
    - `gcd`: наибольший общий делитель
    - `lcm`: наименьшее общее кратное
- `EuclideanRing`
    - `quot` (`/~`): частное (евклидово деление)
    - `mod` (`%`): остаток
    - `quotmod` (`/%`): частное и остаток
- `Field`
    - `reciprocal`: обратная операция умножению
    - `div` (`/`): деление
    - `ceil`: округление вверх
    - `floor`: округление вниз
    - `round`: округление до ближайшего
- `NRoot`
    - `nroot`: корень k степени (тип k - `Int`)
    - `sqrt`: квадратный корень
    - `log`: натуральный логарифм
    - `fpow` (`**`): возведение в степень (дробный показатель степени)
