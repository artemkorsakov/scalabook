# Значение символов

Ниже приведён список символов, используемых в библиотеке Cats.

Символы `~>`, `⊥`, `⊤`, `:<:` и `:≺:` можно импортировать с помощью `import cats.*`.

Все остальные символы можно импортировать с помощью `import cats.syntax.all.*`.

## Операторы и символы Cats

| Символ               | Название                                                  | Класс типов             | Сигнатура метода                                                  |
|:---------------------|:----------------------------------------------------------|:------------------------|:------------------------------------------------------------------|
| `fa *> fb`           | правое произведение (product right)                       | `Apply[F[_]]`           | `productR(fa: F[A])(fb: F[B]): F[B]`                              |
| `fa <* fb`           | левое произведение (product left)                         | `Apply[F[_]]`           | `productL(fa: F[A])(fb: F[B]): F[A]`                              |
| `x === y`            | равно (равенство)                                         | `Eq[A]`                 | `eqv(x: A, y: A): Boolean`                                        |
| `x =!= y`            | не равно (неравенство)                                    | `Eq[A]`                 | `neqv(x: A, y: A): Boolean`                                       |
| `fa >>= f`           | плоское отображение                                       | `FlatMap[F[_]]`         | `flatMap(fa: F[A])(f: A => F[B]): F[B]`                           |
| `fa >> fb`           | затем (followed by)                                       | `FlatMap[F[_]]`         | `>>(fb: => F[B]): F[B]`                                           |
| `x \|-\| y`          | удаление (remove)                                         | `Group[A]`              | `remove(x: A, y: A): A`                                           |
| `x > y`              | больше чем                                                | `PartialOrder[A]`       | `gt(x: A, y: A): Boolean`                                         |
| `x >= y`             | больше или равно                                          | `PartialOrder[A]`       | `gteq(x: A, y: A): Boolean`                                       |
| `x < y`              | меньше чем                                                | `PartialOrder[A]`       | `lt(x: A, y: A): Boolean`                                         |
| `x <= y`             | меньше или равно                                          | `PartialOrder[A]`       | `lteq(x: A, y: A): Boolean`                                       |
| `x \|+\| y`          | комбинация Semigroup                                      | `Semigroup[A]`          | `combine(x: A, y: A): A`                                          |
| `x <+> y`            | комбинация SemigroupK                                     | `SemigroupK[F[_]]`      | `combineK(x: F[A], y: F[A]): F[A]`                                |
| `f <<< g`            | композиция Arrow                                          | `Compose[F[_, _]]`      | `compose(f: F[B, C], g: F[A, B]): F[A, C]`                        |
| `f >>> g`            | композиция Arrow (andThen)                                | `Compose[F[_, _]]`      | `andThen(f: F[A, B], g: F[B, C]): F[A, C]`                        |
| `f &&& g`            | слияние Arrow (merge)                                     | `Arrow[F[_, _]]`        | `merge[A, B, C](f: F[A, B], g: F[A, C]): F[A, (B, C)]`            |
| `f -< g`             | комбинация с обходом (combine and bypass)                 | `Arrow[F[_, _]]`        | `combineAndByPass[A, B, C](f: F[A, B], g: F[B, C]): F[A, (B, C)]` |
| `F ~> G`             | естественное преобразование (natural transformation)      | `FunctionK[F[_], G[_]]` | псевдоним для `FunctionK`                                         |
| `F :<: G`            | инъекция (injectK)                                        | `InjectK[F[_], G[_]]`   | псевдоним для `InjectK`                                           |
| `F :≺: G`            | инъекция (injectK)                                        | `InjectK[F[_], G[_]]`   | псевдоним для `InjectK`                                           |
| `fa &> fb`           | параллельное правое произведение (parallel product right) | `Parallel[M[_]]`        | `parProductR[A, B](ma: M[A])(mb: M[B]): M[B]`                     |
| `fa <& fb`           | параллельное левое произведение (parallel product left)   | `Parallel[M[_]]`        | `parProductL[A, B](ma: M[A])(mb: M[B]): M[A]`                     |
| `⊥`                  | дно (bottom)                                              | Н/Д                     | `Nothing`                                                         |
| `⊤`                  | верх (top)                                                | Н/Д                     | `Any`                                                             |
| `fa << fb` (устарел) | левое произведение (product left)                         | `FlatMap[F[_]]`         | `productL(fa: F[A])(fb: F[B]): F[A]`                              |

## Подробные пояснения

### Операторы для `Apply` (`*>`, `<*`)

- **`fa *> fb` (product right)**: Выполняет `fa` и `fb`, возвращая результат `fb`. 
  Используется, когда вам важен только эффект от `fa`, а значение из него игнорируется.
- **`fa <* fb` (product left)**: Выполняет `fa` и `fb`, возвращая результат `fa`. 
  Используется, когда вам важен только эффект от `fb` (например, для логирования или проверки условий), а его значение игнорируется.

### Операторы для `Eq` (`===`, `=!=`)

- **`x === y` (равенство)**: Альтернатива `==`, но использует экземпляр `Eq` (класс типов для равенства). 
  Гарантирует отсутствие побочных эффектов и согласованность с `hashCode`.
- **`x =!= y` (неравенство)**: Отрицание `===` — проверяет, что значения не равны.

### Операторы для `FlatMap` (`>>=`, `>>`)

- **`fa >>= f` (flatMap)**: Связывает два монадических вычисления. Эквивалент `fa.flatMap(f)`. 
  Позволяет использовать результат первого вычисления в качестве входных данных для второго.
- **`fa >> fb` (followed by)**: Выполняет `fa`, игнорирует его результат, затем выполняет `fb`. 
  Полезно для последовательных действий без передачи данных между ними.

### Оператор для `Group` (`|-|`)

- `x |-| y` **(remove)**: Операция вычитания в группе. Для числовых групп это обычное вычитание. 
  Для других типов (например, множеств) это может быть операция удаления элемента.

### Операторы для `PartialOrder` (`>`, `>=`, `<`, `<=`)

- Операторы сравнения для частично упорядоченных типов. 
  В отличие от стандартных `>`, `<` в Scala, эти операторы используют экземпляр `PartialOrder`, 
  что позволяет работать с типами, не имеющими полного порядка (например, с числами с плавающей запятой, где есть NaN).

### Оператор для `Semigroup` (`|+|`)

- `x |+| y` **(Semigroup combine)**: Ассоциативная операция объединения. 
  Для чисел это сложение, для строк — конкатенация, для списков — объединение.

### Оператор для `SemigroupK` (`<+>`)

- **`x <+> y` (SemigroupK combine)**: Версия `|+|` на уровне конструкторов типов. 
  Объединяет два контейнера одного типа (например, два списка или две опции). 
  Для `Option`: `Some(1) <+> Some(2)` даст `Some(1)` (первый успешный).

### Операторы для `Compose` и `Arrow` (`<<<`, `>>>`, `&&&`, `-<`)

Эти операторы работают со стрелками (`Arrow`) — обобщением функций, позволяющим выполнять вычисления с контекстом.

- **`f <<< g` (compose)**: Композиция стрелок: сначала `g`, затем `f`. Аналог `f.compose(g)`.
- **`f >>> g` (andThen)**: Композиция стрелок: сначала `f`, затем `g`. Аналог `f.andThen(g)`.
- **`f &&& g` (merge)**: Применяет `f` и `g` к одному и тому же входному значению, возвращая кортеж результатов.
- **`f -< g` (combine and bypass)**: Комбинирует `f` и `g`, пропуская часть вычислений. 
  Более сложный оператор для специфических сценариев.

### Операторы для естественных преобразований (`~>`, `:<:`, `:≺:`)

- **`F ~> G` (natural transformation)**: Псевдоним для `FunctionK[F, G]`. 
  Представляет преобразование из одного функтора в другой, сохраняющее структуру.
- **`F :<: G` и `F :≺: G` (injectK)**: Псевдонимы для `InjectK[F, G]`. 
  Используются в свободных монадах для работы с алгебрами, позволяя «внедрять» один функтор в другой.

### Операторы для `Parallel` (`&>`, `<&`)

- **`fa &> fb` (parallel product right)**: Параллельная версия `*>`. 
  Выполняет `fa` и `fb` параллельно (где это возможно), возвращая результат `fb`.
- **`fa <& fb` (parallel product left)**: Параллельная версия `<*`. 
  Выполняет `fa` и `fb` параллельно, возвращая результат `fa`.

### Специальные символы (`⊥`, `⊤`)

- **`⊥` (bottom)**: Представляет тип `Nothing` — тип без значений. 
  Используется в теории категорий и функциональном программировании для обозначения «дна».
- **`⊤` (top)**: Представляет тип `Any` — универсальный тип. 
  Используется для обозначения «верха».

### Устаревший оператор (`<<`)

- **`fa << fb` (product left)**: Устаревший вариант `fa <* fb`. Не рекомендуется к использованию в новом коде.

## Как импортировать символы

**Группа 1** (импортируется через `import cats.*`):

- `~>`, `⊥`, `⊤`, `:<:`, `:≺:`

**Группа 2** (импортируется через `import cats.syntax.all.*`):

- Все остальные символы: `*>`, `<*`, `===`, `=!=`, `>>=`, `>>`, `|-|`, `>`, `>=`, `<`, `<=`, `|+|`, `<+>`, 
  `<<<`, `>>>`, `&&&`, `-<`, `&>`, `<&`, `<<`

**Совет:** Для точечного импорта можно использовать соответствующие пакеты, например:

- `import cats.syntax.eq.*` для `===` и `=!=`
- `import cats.syntax.semigroup.*` для `|+|`
