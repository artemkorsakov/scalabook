# Параллелизм

## Параллелизм с помощью чистых функций

Чистые функции без побочных эффектов идеально подходят для параллельных вычислений, 
поскольку их можно свободно комбинировать и выполнять в любом порядке 
без риска возникновения состояний гонки или других проблем параллелизма.

Рассмотрим операцию суммирования чисел:

```dotty
def sum(ints: Seq[Int]): Int =
  ints.foldLeft(0)((a, b) => a + b)
```

Эта реализация:

1. Использует строго последовательное вычисление через `foldLeft`
2. Проходит коллекцию строго слева направо
3. На каждом шаге выполняет операцию сложения с аккумулятором
4. Имеет временную сложность O(n), где n - размер коллекции

Главный недостаток - отсутствие возможности распараллеливания из-за строгой последовательной природы `foldLeft`.

Альтернативный подход - алгоритм "разделяй и властвуй":

```dotty
def sum(ints: IndexedSeq[Int]): Int =
  if ints.length <= 1 then
    ints.headOption.getOrElse(0)
  else
    val (l, r) = ints.splitAt(ints.length / 2)
    sum(l) + sum(r)

sum(IndexedSeq(1, 2, 3, 4, 5))
// 15
```

Ключевые особенности этого подхода:

1. Коллекция делится на две части с помощью `splitAt`
2. Каждая часть обрабатывается рекурсивно независимо
3. Результаты объединяются простым сложением
4. Используется `IndexedSeq` для эффективного разбиения
5. Глубина рекурсии log₂(n)

Главное преимущество - естественная возможность распараллеливания рекурсивных вызовов `sum(l)` и `sum(r)`, так как они:

1. Не зависят друг от друга
2. Не имеют общих изменяемых состояний
3. Могут выполняться в разных потоках

## Тип данных для параллельных вычислений

Для безопасных параллельных вычислений в функциональном стиле определяем специальный тип `Par[A]`, 
представляющий отложенное параллельное вычисление, возвращающее значение типа `A`.

Базовый API:

```dotty
opaque type Par[A] = ???

object Par:
  def unit[A](a: A): Par[A] =
    ???
    
  def fork[A](a: => Par[A]): Par[A] =
    ???
    
  def lazyUnit[A](a: => A): Par[A] =
    fork(unit(a))

  extension [A](pa: Par[A])
    def run: A =
      ???
      
    def map2[B, C](pb: Par[B])(f: (A, B) => C): Par[C] =
      ???
```

Подробное описание операций:

1. `unit(a: A): Par[A]`  
    - Преобразует значение в параллельный контекст
    - Не выполняет реальных вычислений до вызова `run`
    - Гарантирует, что значение будет доступно при необходимости

2. `fork(a: => Par[A]): Par[A]`  
    - Помечает вычисление для параллельного выполнения
    - Принимает параметр по имени (ленивый)
    - Не начинает вычисление немедленно
    - Планирует выполнение в отдельном потоке (или пуле потоков)

3. `lazyUnit(a: => A): Par[A]`  
    - Комбинация `unit` и `fork`
    - Позволяет отложить вычисление и выполнить его параллельно
    - Полезен для обертки побочных эффектов

4. `run: A`  
    - Запускает параллельное вычисление
    - Блокирует текущий поток до завершения
    - Возвращает результат вычисления
    - Управляет пулом потоков и синхронизацией

5. `map2[B, C](pb: Par[B])(f: (A, B) => C): Par[C]`  
    - Комбинирует два параллельных вычисления
    - Применяет функцию `f` к результатам
    - Вычисления могут выполняться параллельно
    - Сохраняет порядок применения функции

Пример реализации параллельного суммирования:

```dotty
def sum(ints: IndexedSeq[Int]): Par[Int] =
  if ints.size <= 1 then
    Par.unit(ints.headOption.getOrElse(0))
  else
    val (l, r) = ints.splitAt(ints.size / 2)
    Par.fork(sum(l)).map2(Par.fork(sum(r)))(_ + _)
```

Ключевые моменты реализации:

1. Базовый случай обрабатывает пустые и одноэлементные коллекции
2. Разбиение коллекции на примерно равные части
3. Рекурсивное вычисление сумм для частей
4. Явное указание параллельности через `fork`
5. Комбинирование результатов через `map2`

## Законы параллельных вычислений

Для корректной работы параллельных вычислений должны соблюдаться определенные законы.

Основной закон (закон сохранения):

```dotty
unit(x).map(f) == unit(f(x))
```

Это означает, что:

1. Поднятие значения и последующее применение функции эквивалентно поднятию результата применения функции
2. Гарантирует сохранение семантики при параллельном выполнении

## Упражнения

### Упражнение 8.1.1: Параллельное вычисление произведения чисел

> [Репозиторий с упражнениями и инструкцией по выполнению][sample]

**Задача:**

Реализуйте параллельное вычисление произведения чисел в коллекции, используя подход "разделяй и властвуй". 

```dotty
def product(ints: IndexedSeq[Int]): Par[Int] =
  ???
```

**Примеры**:

```dotty
product(IndexedSeq(1, 2, 3, 4, 5)).run(service).get()
// Результат: 120

product(IndexedSeq.empty[Int]).run(service).get()
// Результат: 1 (нейтральный элемент умножения)
```  

@:note(🔍 Показать решение)

Решение реализует параллельное вычисление произведения чисел в коллекции по стратегии «разделяй и властвуй»: 
для пустой последовательности возвращается нейтральный элемент `1`, для одного элемента — сам элемент, 
а для больших коллекций массив рекурсивно делится пополам, 
после чего произведения половин вычисляются параллельно (через `fork`) и комбинируются умножением (через `map2`). 

```dotty
def product(doubles: IndexedSeq[Int]): Par[Int] =
  if doubles.size <= 1 then
    Par.unit(doubles.headOption.getOrElse(1))
  else
    val (l, r) = doubles.splitAt(doubles.size / 2)
    Par.fork(product(l)).map2(Par.fork(product(r)))(_ * _)
```

### Упражнение 8.1.2: Параллельный поиск максимального элемента

**Задача:**  

Реализуйте функцию для параллельного поиска максимального элемента в коллекции целых чисел. 
Функция должна возвращать `Option[Int]` для корректной обработки пустых коллекций.

```dotty
def max(ints: IndexedSeq[Int]): Par[Option[Int]] =
  ???
```

**Требования:**

- Обрабатывайте пустые коллекции (возвращайте `None`)
- Для непустых коллекций применяйте рекурсивное разделение
- Используйте `Math.max` для сравнения элементов
- Сохраняйте семантику `Option` при комбинировании результатов

**Примеры:**

```dotty
max(IndexedSeq(3, 1, 4, 2)).run(service).get() // Some(4)
max(IndexedSeq.empty[Int]).run(service).get()  // None
max(IndexedSeq(42)).run(service).get()         // Some(42)
```

@:note(🔍 Показать решение)

Решение реализует параллельный поиск максимального элемента в коллекции: 
для коллекций размером ≤1 элемент возвращается `headOption`, 
а для больших массивов последовательность рекурсивно делится пополам, 
после чего максимумы в каждой половине вычисляются параллельно (через `fork`), 
а результаты комбинируются через `map2` с обработкой всех вариантов `Option` 
(сравнение значений через `Math.max`, сохранение непустых значений при наличии `None`). 

```dotty
def max(ints: IndexedSeq[Int]): Par[Option[Int]] =
  if ints.size <= 1 then
    Par.unit(ints.headOption)
  else
    val (l, r) = ints.splitAt(ints.size / 2)
    Par.fork(max(l)).map2(Par.fork(max(r))) {
      case (Some(a), Some(b)) => Some(Math.max(a, b))
      case (a, None)          => a
      case (None, b)          => b
    }    
```

### Упражнение 8.1.3: Параллельная проверка условия для всех элементов

**Задача:**  

Реализуйте функцию параллельной проверки, что все элементы коллекции удовлетворяют заданному предикату.

```dotty
def all[A](xs: IndexedSeq[A])(p: A => Boolean): Par[Boolean] =
  ???
```

**Примеры:**

```dotty
val isEven = (x: Int) => x % 2 == 0

all(IndexedSeq(2, 4, 6))(isEven).run(service).get()   // true
all(IndexedSeq(2, 3, 4))(isEven).run(service).get()   // false
all(IndexedSeq.empty[Int])(isEven).run(service).get() // true
```

@:note(🔍 Показать решение)

Функция `all` проверяет, что все элементы коллекции `xs` удовлетворяют предикату `p`, используя параллельные вычисления: 
если коллекция небольшая (размер ≤ 1), результат вычисляется синхронно через `forall`, иначе коллекция делится пополам, 
и проверка выполняется рекурсивно для каждой половины в параллельных потоках с помощью `fork`, 
после чего результаты объединяются через `map2` с логическим `И` (`&&`).

```dotty
def all[A](xs: IndexedSeq[A])(p: A => Boolean): Par[Boolean] =
  if xs.size <= 1 then
    Par.unit(xs.headOption.forall(p))
  else
    val (l, r) = xs.splitAt(xs.size / 2)
    Par.fork(all(l)(p)).map2(Par.fork(all(r)(p)))(_ && _) 
```

### Упражнение 8.1.4: Параллельное преобразование коллекции (map)

**Задача:**  

Реализуйте функцию `parMap` - параллельный аналог стандартной операции `map`, 
которая применяет функцию преобразования к каждому элементу коллекции.

```dotty
def parMap[A, B](xs: IndexedSeq[A])(f: A => B): Par[IndexedSeq[B]] =
  ???
```

**Примеры:**

```dotty
val increment = (x: Int) => x + 1

parMap(IndexedSeq(1, 2, 3))(increment).run(service).get()   // IndexedSeq(2, 3, 4)
parMap(IndexedSeq.empty[Int])(increment).run(service).get() // IndexedSeq()
parMap(IndexedSeq(10))(increment).run(service).get()        // IndexedSeq(11)
```

@:note(🔍 Показать решение)

```dotty
def parMap[A, B](xs: IndexedSeq[A])(f: A => B): Par[IndexedSeq[B]] =
  if xs.size <= 1 then
    Par.unit(xs.map(f))
  else
    val (l, r) = xs.splitAt(xs.size / 2)
    Par.fork(parMap(l)(f)).map2(Par.fork(parMap(r)(f)))(_ ++ _)
```

### Упражнение 8.1.5: Параллельный reduce

**Задача:**  

Реализуйте функцию `reduce` - параллельный аналог стандартной операции свертки, 
которая комбинирует элементы коллекции с помощью ассоциативной бинарной операции.

```dotty
def reduce[A](xs: IndexedSeq[A])(op: (A, A) => A): Par[Option[A]] =
  ???
```

**Примеры:**

```dotty
val sumOp = (a: Int, b: Int) => a + b

reduce(IndexedSeq(1, 2, 3, 4))(sumOp).run(service).get() // Some(10)
reduce(IndexedSeq.empty[Int])(sumOp).run(service).get()  // None
reduce(IndexedSeq(5))(sumOp).run(service).get()          // Some(5)
```

@:note(🔍 Показать решение)

Функция `reduce` параллельно сводит коллекцию `xs` с помощью операции `op`: 
если коллекция пуста, возвращается `None`, если содержит один элемент — `Some(xs.head)`, 
иначе коллекция делится пополам, и каждая часть обрабатывается рекурсивно в параллельных потоках через `fork`, 
после чего результаты объединяются с помощью `map2`, 
применяя `op` к значениям внутри `Option` или сохраняя оставшееся значение, 
если один из вариантов — `None`.

```dotty
def reduce[A](xs: IndexedSeq[A])(op: (A, A) => A): Par[Option[A]] =
  if xs.isEmpty then Par.unit(None)
  else if xs.size == 1 then Par.unit(Some(xs.head))
  else
    val (l, r) = xs.splitAt(xs.size / 2)
    Par.fork(reduce(l)(op)).map2(Par.fork(reduce(r)(op))) {
      case (Some(a), Some(b)) => Some(op(a, b))
      case (a, None)          => a
      case (None, b)          => b
    }
```
