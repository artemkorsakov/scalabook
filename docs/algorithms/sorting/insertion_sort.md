# Сортировка вставками

**Алгоритм:**

В начальный момент отсортированная последовательность пуста. 
На каждом шаге [алгоритма сортировки вставками](https://ru.wikipedia.org/wiki/%D0%A1%D0%BE%D1%80%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%BA%D0%B0_%D0%B2%D1%81%D1%82%D0%B0%D0%B2%D0%BA%D0%B0%D0%BC%D0%B8)
выбирается один из элементов входных данных и помещается на нужную позицию в уже отсортированной последовательности до тех пор, 
пока набор входных данных не будет исчерпан. 
В любой момент времени в отсортированной последовательности элементы удовлетворяют требованиям к выходным данным алгоритма.

**Оценка:**

- **Время**:
  - Худшее - \\(O(n^{2})\\)
  - Лучшее - \\(O(n)\\) 
  - Среднее - \\(O(n^{2})\\)
- **Память** - \\(O(n)\\)

**Код:**

Реализация сортировки вставками с помощью ФП может выглядеть так:

- Инициализация: Начинаем с двух списков: 
    - `as`, который содержит элементы для сортировки, 
    - и `bs`, который изначально пустой и будет содержать отсортированные элементы.
- Основной процесс сортировки:
    - Проверяем, пуст ли список `as`. Если он пуст, это означает, что все элементы были обработаны, и мы можем вернуть отсортированный список `bs`.
    - Если `as` не пуст, берем первый элемент `h` из `as` и оставшиеся элементы `t`.
    - Вставка элемента: Вызываем функцию `insert`, передавая ей элемент `h` и текущий отсортированный список `bs`.
    - Функция `insert` вставляет элемент `h` в правильную позицию в списке `bs`, чтобы сохранить порядок.
- Внутри функции `insert`:
    - Если `h` больше первого элемента списка `bs`, то добавляем первый элемент в начало списка, который получается после вставки `h` в оставшуюся часть списка `bs`.
    - Если `h` меньше или равен первому элементу `bs`, добавляем `h` в начало `bs`.
- Рекурсия: После вставки элемента `h`, вызываем `sort` снова, передавая оставшиеся элементы `t` и обновленный список `bs`, который теперь включает вставленный элемент.
- Завершение: Процесс продолжается до тех пор, пока все элементы из `as` не будут обработаны и добавлены в `bs`.

```dotty
def insertionSort[A: Ordering](list: List[A]): List[A] =
  @tailrec
  def sort(as: List[A], bs: List[A]): List[A] = as match
    case Nil    => bs
    case h :: t => sort(t, insert(h, bs))

  def insert(h: A, bs: List[A]): List[A] = bs match
    case hb :: tb if h > hb => hb :: insert(h, tb)
    case _                  => h :: bs

  sort(list, Nil)
  
insertionSort(List(3, 1, 4, 2))
// List(1, 2, 3, 4)  
```
