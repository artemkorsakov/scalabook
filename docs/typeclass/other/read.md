# Read

`Read` — это класс типов, который предоставляет абстракцию для преобразования строк в объекты определённого типа. 
Он является обратной операцией к классу типов [`Show`](show.md) и используется для парсинга строк в значения.

**Где применяется?**

- **Парсинг данных**: Преобразование строк, полученных из файлов, сетевых запросов или пользовательского ввода, в объекты.
- **Конфигурация**: Чтение и интерпретация настроек из конфигурационных файлов.
- **Сериализация**: Десериализация данных из текстовых форматов (например, JSON, CSV).
- **Валидация**: Проверка и преобразование строк в корректные значения, например, числа или даты.

**Примеры использования:**

- Преобразование строки `"42"` в число `42`.
- Парсинг строки `"2023-10-01"` в объект даты.
- Чтение конфигурационного параметра `"timeout=30"` и преобразование его в целое число.
- Десериализация JSON-строки в объект пользователя.

**Преимущества:**

- **Типобезопасность**: `Read` требует явной реализации для каждого типа, что делает парсинг более предсказуемым.
- **Гибкость**: Вы можете определять собственные правила для парсинга различных типов.
- **Интеграция с библиотеками**: Используется в библиотеках для работы с конфигурациями, сериализацией и валидацией.

**Альтернатива стандартным методам:**  

В отличие от методов вроде `Integer.parseInt`, `Read` предоставляет более универсальный и типобезопасный подход, 
позволяя избежать ошибок, связанных с неверным форматом строки.

## Формальное определение

`Read` — это класс типов, который предоставляет абстракцию для преобразования строк в объекты определённого типа.
Функция `read` принимает строку и возвращает тип, который является членом `Read`.

Для корректной реализации `Read` должны выполняться следующие законы:

- **Консистентность**: Для корректной строки `s`, соответствующей типу `A`, 
  `read(s)` должен возвращать `Right(value)`, где `value` — корректное значение типа `A`.
- **Обратимость**: Если `read(s)` возвращает `Right(value)`, 
  то `Show[A].show(value)` должно возвращать строку, эквивалентную `s` (если `Show` также реализован).
- **Обработка ошибок**: Для некорректных строк `read(s)` должен возвращать `Left` с описанием ошибки.

## Определение в виде кода на Scala

```dotty
trait Read[F]:
  def read(s: String): Either[String, F]
```

- **Типовой параметр `A`**: `Read` параметризуется типом `A`, для которого определяется парсинг.
- **Метод `read`**: Метод `read` принимает строку и возвращает либо успешно распарсенное значение типа `A`, 
  либо сообщение об ошибке в виде строки.

### Пример использования

```dotty
object Read:
  given Read[Int] with
    def read(s: String): Either[String, Int] =
      s.toIntOption.toRight(s"Invalid integer: $s")

summon[Read[Int]].read("42")
// Right(42)
summon[Read[Int]].read("abc")
// Left("Invalid integer: abc")
```
