# Ресурсы по Scala

Структурированная подборка материалов для изучения и работы со Scala. Все ресурсы организованы по категориям и упорядочены для удобного поиска.

## Категории материалов

### Книги

- Полные руководства по языку Scala
- От основ синтаксиса до продвинутых тем:
    - Функциональное программирование
    - Работа с коллекциями
    - Параллельные вычисления
    - Оптимизация кода

### Курсы

- Онлайн-курсы для разного уровня подготовки
- Интерактивные обучающие программы
- Вебинары с практическими занятиями

### Практика

- Упражнения для закрепления знаний:
    - Простые задачи для начинающих
    - Сложные кейсы для опытных разработчиков
    - Реальные примеры применения

### Статьи и блоги

- Технические статьи и руководства
- Примеры использования библиотек
- Разбор новых возможностей языка
- Лучшие практики разработки

### Видеоматериалы

- Записи конференций и митапов
- Видеоуроки по различным аспектам Scala
- Скринкасты и live-кодинг

## Система сортировки

Материалы организованы по следующей схеме:

- По версии Scala:
    - Scala 3 + версионно-независимые
    - Scala 2
- По языку контента:
    - На русском
    - На английском
- В алфавитном порядке внутри категорий
