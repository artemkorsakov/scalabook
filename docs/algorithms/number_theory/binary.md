# Двоичные числа и другие системы счисления

## Степень двойки

> Дано число `x`. Требуется определить, является ли `x` степенью двойки.

**Алгоритм:**

Побитовое И для `x` и `(x - 1)` должно возвращать `0`.

**Пояснение** и **Пример:**

Побитовое И (AND) между двумя числами возвращает 1 только в тех позициях, где оба числа имеют 1 в соответствующих битах. 
Рассмотрим различные примеры.

а) Степень двойки

В общем случае, если \\(x = 2^n\\), то в двоичном представлении x будет выглядеть как \\(1000...0\\) (один бит 1 и n нулей).
Когда мы вычитаем 1 из степени двойки, то получаем число, 
у которого все биты правее (младшие) установленного бита 1 становятся 1, а сам бит 1 становится 0.
Теперь рассмотрим побитовое И между `x` и `(x - 1)`:
Для \\(x = 2^n\\):

- \\(x = 1000...0\_2\\)
- \\(x - 1 = 0111...1\_2\\)
- \\(x \& (x - 1) = 1000...0\_2 \& 0111...1\_2 = 0000...0\_2\\)

Результат равен 0.

б) Другие числа

Теперь рассмотрим, что происходит, если x не является степенью двойки:

Если x имеет более одного бита, установленного в 1, то при вычитании 1 мы не получим все нули в результате побитового И. Например:
Пусть x = 6 (в двоичном: \\(0110\_2\\)):

- \\(x - 1 = 5\\) (в двоичном: \\(0101\_2\\))
- \\(x \& (x - 1) = 0110\_2 \& 0101\_2 = 0100\_2\\) (результат не равен 0).
  
**Оценка:**

- **Время** - O(1)
- **Память** - O(1)

**Код:**

```dotty
def isPowerOfTwo(x: Int): Boolean = (x & (x - 1)) == 0

isPowerOfTwo(16) // true
```

## Количество битовых единиц

> Даны два числа, `x` и `y`. Требуется определить, содержат ли они одинаковое количество единиц в битовом представлении.

**Алгоритм:**

- **Шаг 1** (Проверка на ноль): Если одно из чисел равно нулю, 
  то `x` и `y` имеют одинаковое количество единиц в битовом представлении только если оба равны 0.
- **Шаг 2** (Проверка четности и нечетности): Если одно из чисел четное, 
  а другое нечетное, то делим четное число на 2 и возвращаемся к **Шагу 1**.
- **Шаг 3** (Рекурсивный вызов): Если оба четные или оба нечетные,
  то делим оба числа на 2 и возвращаемся к **Шагу 1**.

**Пример:**

Рассмотрим пример расчета для пары (6, 3):

- x = 6 (четное), y = 3 (нечетное) → возвращаемся в начало алгоритма с парой (3, 3).
- x = 3 (нечетное), y = 3 (нечетное) → возвращаемся с (1, 1).
- x = 1 (нечетное), y = 1 (нечетное) → возвращаемся с (0, 0).
- x = 0, y = 0 → возвращаем `true`.

Таким образом, для пары (6, 3) алгоритм вернет `true`.

**Пояснение:**

- **Шаг 1** (Проверка на ноль): Если оба числа равны нулю, то они оба не содержат единиц в битовом представлении.
  Если тольно одно из чисел равно нулю (нет единиц в битовом представлении), 
  то второе содержит как минимум одну единицу в битовом представлении. 
  А это означает, что количество единиц в битовом представлении не одинаково.
- **Шаг 2** (Проверка четности и нечетности): Если числа имеют разную четность, то при делении четного числа на 2 
  количество единиц в его битовом представлении не меняется (удаляется конечный ноль).
  Можно продолжить проверку для нечетного и половины четного.
- **Шаг 3** Если числа имеют одинаковую четность, то они заканчиваются на одну и ту же цифру (0 или 1) в битовом представлении.
  А это означает, то при делении на 2 количество единиц в их битовом представлении либо не изменится, либо уменьшиться на 1
  для обоих чисел. А значит, ответ на вопрос, содержат ли они одинаковое количество единиц в битовом представлении,
  равносильно вопросу, содержат ли они одинаковое количество единиц в битовом представлении после отсечения последней цифры.

**Оценка:**

- **Время** - O(log(n))
- **Память** - O(1)

**Код:**

```dotty
@annotation.tailrec
def isSnoob(x: Int, y: Int): Boolean = 
  if x == 0 && y == 0 then true
  else if x == 0 || y == 0 then false
  else if x % 2 == 1 && y % 2 == 0 then isSnoob(x, y >> 1)
  else if x % 2 == 0 && y % 2 == 1 then isSnoob(x >> 1, y)
  else isSnoob(x >> 1, y >> 1)

isSnoob(11, 13)
// true: "1101", "1011"  
```

## Преобразование десятичного числа в двоичное

> Дано число в десятичной системе счисления. Требуется преобразовать это число в двоичную систему счисления.

**Алгоритм:**

Алгоритм конвертации:

- **Шаг 1**. Начиная с заданного числа, составить последовательность чисел таким образом, 
  чтобы последующее число было половиной предыдущего. 
  Продолжить до тех пор, пока последний элемент не будет удовлетворять условию 2 > x > 0,
  где x — последнее число в последовательности.
  Формально S = {\\(x\_{1}\\), \\(x\_{2}\\),..., \\(x\_{n}\\)},
  где \\(x\_{2}\\) = \\(\frac{x\_{1}}{2}\\), \\(x\_{3}\\) = \\(\frac{x\_{2}}{2}\\) и т.д., и 2 > \\(x\_{n}\\) > 0.
- **Шаг 2**. Для каждого числа из приведенного выше списка разделить на 2 и хранить остаток в контейнере.
- **Шаг 3**. Теперь контейнер содержит двоичные эквивалентные биты в обратном порядке, \\(b\_{1}b\_{2}...b\_{n}\\),
  поэтому надо изменить порядок, чтобы получить двоичное эквивалентное число, \\(b\_{n}...b\_{2}b\_{1}\\).

**Пример:**

Рассмотрим пример вычисления по заданному алгоритму, начиная с целого числа 13.

- **Шаг 1**. Составим последовательность, деля число на 2 до тех пор, пока не получим значение, удовлетворяющее условию (2 > x > 0).

- \\(x\_1 = 13\\)
- \\(x\_2 = \frac{13}{2} = 6.5\\) (округляем до целого числа: 6)
- \\(x\_3 = \frac{6}{2} = 3\\)
- \\(x\_4 = \frac{3}{2} = 1.5\\) (округляем до целого числа: 1)
- \\(x\_5 = \frac{1}{2} = 0.5\\) (округляем до целого числа: 0)
- Последовательность будет: (S = {13, 6, 3, 1}). \\(x\_5 = 0\\) не удовлетворяет условию (2 > 0 > 0), поэтому завершаем на \\(x\_4 = 1\\).

- **Шаг 2**. Теперь для каждого числа из последовательности разделим на 2 и сохраним остаток.

- Для \\((x\_1 = 13): (13 \mod 2 = 1)\\) (остаток 1)
- Для \\((x\_2 = 6): (6 \mod 2 = 0)\\) (остаток 0)
- Для \\((x\_3 = 3): (3 \mod 2 = 1)\\) (остаток 1)
- Для \\((x\_4 = 1): (1 \mod 2 = 1)\\) (остаток 1)
- Остатки в контейнере: {1, 0, 1, 1}.

- **Шаг 3**. В обратном порядке: (1101).

Таким образом, двоичное эквивалентное число для целого числа 13 по заданному алгоритму равно (1101).

**Пояснение:**

Для любого числа верно следующее: \\(a = \left\lfloor \frac{a}{2} \right\rfloor \times 2 + (a \mod 2)\\).
Следовательно, двоичное представление числа равно двоичному представлению половины числа с добавлением остатка от деления числа на 2.

**Оценка:**

- **Время** - O(log(n))
- **Память** - O(log(n))

**Код:**

```dotty
def decToBinConv(x: Int): String =
  val seqOfDivByTwo = Iterator.iterate(x)(a => a / 2)
  val binList = seqOfDivByTwo
    .takeWhile(a => a > 0)
    .map(a => a % 2)
  binList.mkString.reverse

decToBinConv(8) // "1000"
decToBinConv(7) // "111"  
```

## Палиндром

[Палиндром](https://ru.wikipedia.org/wiki/%D0%9F%D0%B0%D0%BB%D0%B8%D0%BD%D0%B4%D1%80%D0%BE%D0%BC) -
число, буквосочетание, слово или текст, одинаково читающееся в обоих направлениях.

> Дано число x. Требуется определить, является ли это число палиндромом в заданной системе счисления.

**Алгоритм:**

- **Шаг 1** (Базовые условия: ноль). Если число равно нулю, то оно палиндром. Иначе переходим к следующему шагу.
- **Шаг 2** (Базовые условия: делимость на основание). Если число делится на основание системы счисления, 
  то оно не является палиндромом. Иначе переходим к следующему шагу.
- **Шаг 3** (Сравнение числа с его перевернутым). Присвоить \\(k \leftarrow number, r \leftarrow 0\\).
  Если \\(k \le r\\), то число является палиндромом только, если \\(k = r\\) или \\(k = \frac{r}{base}\\). Иначе число не является палиндромом.
  Если \\(k > r\\), то переходим к следующему шагу.
- **Шаг 4** (Обработка числа). Присвоить \\(k \leftarrow \frac{k}{base}, r \leftarrow r * base + k \% base\\).

**Пример:**

Дано число 12321.

- **Шаг 1**: 12321 ≠ 0, переходим к следующему шагу.
- **Шаг 2**: 12321 % 10 ≠ 0, переходим к следующему шагу.
- **Шаг 3**: Присваиваем: \\(k \leftarrow 12321, r \leftarrow 0\\). Поскольку \\(k > r\\), переходим к шагу 4.
- **Шаг 4**: 
    - Обрабатываем число.
        - \\(k \leftarrow \frac{12321}{10} = 1232\\)
        - \\(r \leftarrow 0 * 10 + 12321 \% 10 = 1\\)
    - Повторяем шаг 3: \\(k \leftarrow 1232\\), \\(r \leftarrow 1\\). Поскольку \\(k > r\\), переходим к шагу 4.
    - Обрабатываем снова:
        - \\(k \leftarrow \frac{1232}{10} = 123\\)
        - \\(r \leftarrow 1 * 10 + 1232 \% 10 = 12\\)
    - Повторяем шаг 3: \\(k \leftarrow 123\\), \\(r \leftarrow 12\\). Поскольку \\(k > r\\), переходим к шагу 4.    
    - Повторяем:
        - \\(k \leftarrow \frac{123}{10} = 12\\)
        - \\(r \leftarrow 12 * 10 + 123 \% 10 = 123\\)
    - Теперь \\(k \leq r\\) и \\(k = \frac{r}{base}\\). Значит, 12321 является палиндромом.

**Пояснение:**

- **Шаг 1**: 0 является палиндромом в любой системе счисления.
- **Шаг 2**: Если число больше 0 и делится на основание системы счисления, 
  то такое число не может быть палиндромом из-за того, что начинается на 1 и оканчивается на 0.
- **Шаг 3**: В переменной k хранится первая половина числа, а в переменной r - перевернутая вторая половина числа.
  Если число является палиндромом, то первая и вторая половины числа должны быть равны в случае, если число содержит четное количество цифр.
  Если число содержит нечетное количество цифр, то первая половина числа должна равняться второй половине без последней цифры.
- **Шаг 4**: Вычисление k происходит путем последовательного деления k на основание, чтобы убрать последнюю цифру,
  а r - путем умножения r на основание и сложения остатка от деления k (добавляем последнюю цифру k в конец r).

**Оценка:**

- **Время** - O(log(n))
- **Память** - O(1)

**Код:**

```dotty
def isPalindrome(number: Long): Boolean = isPalindrome(number, 10)

def isPalindrome(number: Long, base: Int): Boolean =
  number == 0 || number > 0 && number % base != 0 && {
    def loop(k: Long, r: Long): Boolean =
      if k <= r then k == r || k == r / base
      else loop(k / base, r * base + k % base)
    loop(number, 0L)
  }

isPalindrome(12321) // true  
```
