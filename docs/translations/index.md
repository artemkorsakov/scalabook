# Переводы и Решения задач

Этот раздел посвящён переводам на русский язык статей, учебных материалов 
и докладов по функциональному программированию на Scala. 
Здесь собраны работы, охватывающие темы:

- Функциональное программирование
- Практическое применение Scala (Cats Effect, fs2, ZIO)
- Оптимизация и архитектура приложений

Также здесь представлен обширный сборник решений разнообразных упражнений, задач и головоломок,
которые были взяты из различных учебников, задачников,
а также из практических заданий, предлагаемых на курсах и в онлайн-ресурсах.

Цель раздела — сделать качественные материалы доступными для русскоязычной аудитории, сохраняя точность терминологии и смысла оригиналов.
