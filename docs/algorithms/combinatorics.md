# Комбинаторика

## Введение

Комбинаторика — это раздел математики, который занимается изучением и подсчетом различных комбинаций и перестановок объектов. 
Этот раздел имеет глубокие корни в истории математики, начиная с работ Леонардо Пизанского (Фибоначчи) 
и продолжаясь до современных исследований в области теории графов, теории вероятностей и алгоритмов.

**Основные задачи комбинаторики:**

- **Подсчет количества комбинаций:** Сколькими способами можно выбрать `k` объектов из `n`?
- **Подсчет количества перестановок:** Сколькими способами можно упорядочить `n` объектов?
- **Подсчет количества разбиений:** Сколькими способами можно разбить множество на подмножества?

**Основные понятия комбинаторики:**

- **Факториал:** Произведение всех натуральных чисел от `1` до `n`. Обозначается `n!`.
- **Перестановка:** Упорядоченный набор из `n` элементов. Количество перестановок из `n` элементов равно `n!`.
- **Сочетание:** Подмножество из `k` элементов, выбранных из `n` элементов. Количество сочетаний обозначается `C(n, k)` или \\(\binom{n}{k}\\).
- **Размещение:** Упорядоченный набор из `k` элементов, выбранных из `n` элементов. Количество размещений обозначается `A(n, k)`.

**Методы комбинаторики:**

- **Принцип умножения:** Если первый элемент можно выбрать `m` способами, а второй элемент — `n` способами, 
  то общее количество способов выбрать пару элементов равно `m * n`.
- **Принцип сложения:** Если первый элемент можно выбрать `m` способами, а второй элемент — `n` способами, 
  и эти способы выбора не пересекаются, то общее количество способов выбрать один элемент равно `m + n`.
- **Рекуррентные соотношения:** Метод, позволяющий выразить количество комбинаций через меньшие значения.
- **Генерация функций:** Метод, позволяющий представлять комбинаторные объекты в виде формальных степенных рядов.
