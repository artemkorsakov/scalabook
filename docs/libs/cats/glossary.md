# Глоссарий

## Значение символов

Ниже приведён список символов, используемых в библиотеке Cats.

Символы `~>`, `⊥`, `⊤`, `:<:` и `:≺:` можно импортировать с помощью `import cats.*`.

Все остальные символы можно импортировать с помощью `import cats.syntax.all.*`.

## Операторы и символы Cats

| Символ               | Название                                                  | Класс типов             | Сигнатура метода                                                  |
|:---------------------|:----------------------------------------------------------|:------------------------|:------------------------------------------------------------------|
| `fa *> fb`           | правое произведение (product right)                       | `Apply[F[_]]`           | `productR(fa: F[A])(fb: F[B]): F[B]`                              |
| `fa <* fb`           | левое произведение (product left)                         | `Apply[F[_]]`           | `productL(fa: F[A])(fb: F[B]): F[A]`                              |
| `x === y`            | равно (равенство)                                         | `Eq[A]`                 | `eqv(x: A, y: A): Boolean`                                        |
| `x =!= y`            | не равно (неравенство)                                    | `Eq[A]`                 | `neqv(x: A, y: A): Boolean`                                       |
| `fa >>= f`           | плоское отображение                                       | `FlatMap[F[_]]`         | `flatMap(fa: F[A])(f: A => F[B]): F[B]`                           |
| `fa >> fb`           | затем (followed by)                                       | `FlatMap[F[_]]`         | `>>(fb: => F[B]): F[B]`                                           |
| `x \|-\| y`          | удаление (remove)                                         | `Group[A]`              | `remove(x: A, y: A): A`                                           |
| `x > y`              | больше чем                                                | `PartialOrder[A]`       | `gt(x: A, y: A): Boolean`                                         |
| `x >= y`             | больше или равно                                          | `PartialOrder[A]`       | `gteq(x: A, y: A): Boolean`                                       |
| `x < y`              | меньше чем                                                | `PartialOrder[A]`       | `lt(x: A, y: A): Boolean`                                         |
| `x <= y`             | меньше или равно                                          | `PartialOrder[A]`       | `lteq(x: A, y: A): Boolean`                                       |
| `x \|+\| y`          | комбинация Semigroup                                      | `Semigroup[A]`          | `combine(x: A, y: A): A`                                          |
| `x <+> y`            | комбинация SemigroupK                                     | `SemigroupK[F[_]]`      | `combineK(x: F[A], y: F[A]): F[A]`                                |
| `f <<< g`            | композиция Arrow                                          | `Compose[F[_, _]]`      | `compose(f: F[B, C], g: F[A, B]): F[A, C]`                        |
| `f >>> g`            | композиция Arrow (andThen)                                | `Compose[F[_, _]]`      | `andThen(f: F[A, B], g: F[B, C]): F[A, C]`                        |
| `f &&& g`            | слияние Arrow (merge)                                     | `Arrow[F[_, _]]`        | `merge[A, B, C](f: F[A, B], g: F[A, C]): F[A, (B, C)]`            |
| `f -< g`             | комбинация с обходом (combine and bypass)                 | `Arrow[F[_, _]]`        | `combineAndByPass[A, B, C](f: F[A, B], g: F[B, C]): F[A, (B, C)]` |
| `F ~> G`             | естественное преобразование (natural transformation)      | `FunctionK[F[_], G[_]]` | псевдоним для `FunctionK`                                         |
| `F :<: G`            | инъекция (injectK)                                        | `InjectK[F[_], G[_]]`   | псевдоним для `InjectK`                                           |
| `F :≺: G`            | инъекция (injectK)                                        | `InjectK[F[_], G[_]]`   | псевдоним для `InjectK`                                           |
| `fa &> fb`           | параллельное правое произведение (parallel product right) | `Parallel[M[_]]`        | `parProductR[A, B](ma: M[A])(mb: M[B]): M[B]`                     |
| `fa <& fb`           | параллельное левое произведение (parallel product left)   | `Parallel[M[_]]`        | `parProductL[A, B](ma: M[A])(mb: M[B]): M[A]`                     |
| `⊥`                  | дно (bottom)                                              | Н/Д                     | `Nothing`                                                         |
| `⊤`                  | верх (top)                                                | Н/Д                     | `Any`                                                             |
| `fa << fb` (устарел) | левое произведение (product left)                         | `FlatMap[F[_]]`         | `productL(fa: F[A])(fb: F[B]): F[A]`                              |

## Подробные пояснения

### Операторы для `Apply` (`*>`, `<*`)

- **`fa *> fb` (product right)**: Выполняет `fa` и `fb`, возвращая результат `fb`. 
  Используется, когда вам важен только эффект от `fa`, а значение из него игнорируется.
- **`fa <* fb` (product left)**: Выполняет `fa` и `fb`, возвращая результат `fa`. 
  Используется, когда вам важен только эффект от `fb` (например, для логирования или проверки условий), а его значение игнорируется.

### Операторы для `Eq` (`===`, `=!=`)

- **`x === y` (равенство)**: Альтернатива `==`, но использует экземпляр `Eq` (класс типов для равенства). 
  Гарантирует отсутствие побочных эффектов и согласованность с `hashCode`.
- **`x =!= y` (неравенство)**: Отрицание `===` — проверяет, что значения не равны.

### Операторы для `FlatMap` (`>>=`, `>>`)

- **`fa >>= f` (flatMap)**: Связывает два монадических вычисления. Эквивалент `fa.flatMap(f)`. 
  Позволяет использовать результат первого вычисления в качестве входных данных для второго.
- **`fa >> fb` (followed by)**: Выполняет `fa`, игнорирует его результат, затем выполняет `fb`. 
  Полезно для последовательных действий без передачи данных между ними.

### Оператор для `Group` (`|-|`)

- `x |-| y` **(remove)**: Операция вычитания в группе. Для числовых групп это обычное вычитание. 
  Для других типов (например, множеств) это может быть операция удаления элемента.

### Операторы для `PartialOrder` (`>`, `>=`, `<`, `<=`)

- Операторы сравнения для частично упорядоченных типов. 
  В отличие от стандартных `>`, `<` в Scala, эти операторы используют экземпляр `PartialOrder`, 
  что позволяет работать с типами, не имеющими полного порядка (например, с числами с плавающей запятой, где есть NaN).

### Оператор для `Semigroup` (`|+|`)

- `x |+| y` **(Semigroup combine)**: Ассоциативная операция объединения. 
  Для чисел это сложение, для строк — конкатенация, для списков — объединение.

### Оператор для `SemigroupK` (`<+>`)

- **`x <+> y` (SemigroupK combine)**: Версия `|+|` на уровне конструкторов типов. 
  Объединяет два контейнера одного типа (например, два списка или две опции). 
  Для `Option`: `Some(1) <+> Some(2)` даст `Some(1)` (первый успешный).

### Операторы для `Compose` и `Arrow` (`<<<`, `>>>`, `&&&`, `-<`)

Эти операторы работают со стрелками (`Arrow`) — обобщением функций, позволяющим выполнять вычисления с контекстом.

- **`f <<< g` (compose)**: Композиция стрелок: сначала `g`, затем `f`. Аналог `f.compose(g)`.
- **`f >>> g` (andThen)**: Композиция стрелок: сначала `f`, затем `g`. Аналог `f.andThen(g)`.
- **`f &&& g` (merge)**: Применяет `f` и `g` к одному и тому же входному значению, возвращая кортеж результатов.
- **`f -< g` (combine and bypass)**: Комбинирует `f` и `g`, пропуская часть вычислений. 
  Более сложный оператор для специфических сценариев.

### Операторы для естественных преобразований (`~>`, `:<:`, `:≺:`)

- **`F ~> G` (natural transformation)**: Псевдоним для `FunctionK[F, G]`. 
  Представляет преобразование из одного функтора в другой, сохраняющее структуру.
- **`F :<: G` и `F :≺: G` (injectK)**: Псевдонимы для `InjectK[F, G]`. 
  Используются в свободных монадах для работы с алгебрами, позволяя «внедрять» один функтор в другой.

### Операторы для `Parallel` (`&>`, `<&`)

- **`fa &> fb` (parallel product right)**: Параллельная версия `*>`. 
  Выполняет `fa` и `fb` параллельно (где это возможно), возвращая результат `fb`.
- **`fa <& fb` (parallel product left)**: Параллельная версия `<*`. 
  Выполняет `fa` и `fb` параллельно, возвращая результат `fa`.

### Специальные символы (`⊥`, `⊤`)

- **`⊥` (bottom)**: Представляет тип `Nothing` — тип без значений. 
  Используется в теории категорий и функциональном программировании для обозначения «дна».
- **`⊤` (top)**: Представляет тип `Any` — универсальный тип. 
  Используется для обозначения «верха».

### Устаревший оператор (`<<`)

- **`fa << fb` (product left)**: Устаревший вариант `fa <* fb`. Не рекомендуется к использованию в новом коде.

## Как импортировать символы

**Группа 1** (импортируется через `import cats.*`):

- `~>`, `⊥`, `⊤`, `:<:`, `:≺:`

**Группа 2** (импортируется через `import cats.syntax.all.*`):

- Все остальные символы: `*>`, `<*`, `===`, `=!=`, `>>=`, `>>`, `|-|`, `>`, `>=`, `<`, `<=`, `|+|`, `<+>`, 
  `<<<`, `>>>`, `&&&`, `-<`, `&>`, `<&`, `<<`

**Совет:** Для точечного импорта можно использовать соответствующие пакеты, например:

- `import cats.syntax.eq.*` для `===` и `=!=`
- `import cats.syntax.semigroup.*` для `|+|`

## Глоссарий

Это каталог основных функций, классов типов и типов данных в библиотеке **Cats**. 
Он служит обзором возможностей каждого класса с высоты птичьего полета. 
Также он предназначен в качестве справочного материала для пользователей Cats, 
которые могут не помнить ответы на такие вопросы:

- В чем разница между `unit` и `void`?
- Чтобы отбросить первое значение и сохранить только первый эффект, нужно использовать `<*` или `*>`?
- Как заставить вычисление `F[A]` завершиться ошибкой при проверке условия на значении?

Сигнатуры и классы типов в этом документе упрощены (подробнее см. [раздел «Упрощения»](#упрощения)). 
Если вам нужна печатная версия, вы также можете ознакомиться с [cats-cheatsheet](https://arosien.github.io/cats-cheatsheets/typeclasses.pdf).

## Классы типов над `F[_]`

### Functor (Функтор)

[`Functor`](../../typeclass/monad/functor.md) — это класс типов, 
предоставляющий возможность применять функцию к значению внутри контекста (контейнера) без изменения самого контекста.

| Тип                             | Имя метода     | Примечания                                                                                   |
|:--------------------------------|:---------------|:---------------------------------------------------------------------------------------------|
| `F[A] => F[Unit]`               | `void`         | Игнорирует значение внутри контейнера, заменяя его на `Unit`                                 |
| `F[A] => B => F[B]`             | `as`           | Заменяет значение внутри контейнера на переданное значение `B`                               |
| `F[A] => (A => B) => F[B]`      | `map`          | Применяет функцию `A => B` к значению внутри контейнера                                      |
| `F[A] => (A => A1) => F[A1]`    | `mapOrKeep`    | Частичная функция: если определена — применяет, иначе оставляет исходное значение; `A1 >: A` |
| `F[A] => (A => B) => F[(A, B)]` | `fproduct`     | Применяет функцию и сохраняет исходное значение вместе с результатом                         |
| `F[A] => (A => B) => F[(B, A)]` | `fproductLeft` | Применяет функцию и сохраняет результат вместе с исходным значением (порядок изменён)        |
| `F[A] => B => F[(B, A)]`        | `tupleLeft`    | Добавляет значение `B` слева к кортежу                                                       |
| `F[A] => B => F[(A, B)]`        | `tupleRight`   | Добавляет значение `B` справа к кортежу                                                      |
| `(A => B) => (F[A] => F[B])`    | `lift`         | Поднимает обычную функцию до уровня функции над `F`                                          |

### Apply (Аппликативный функтор без `pure`)

[`Apply`](../../typeclass/monad/apply.md) расширяет `Functor`, 
добавляя возможность применять функцию, которая сама находится в контексте.

| Тип                                      | Имя метода | Символ |
|:-----------------------------------------|:-----------|:-------|
| `F[A] => F[B] => F[A]`                   | `productL` | `<*`   |
| `F[A] => F[B] => F[B]`                   | `productR` | `*>`   |
| `F[A] => F[B] => F[(A, B)]`              | `product`  | —      |
| `F[A => B] => F[A] => F[B]`              | `ap`       | `<*>`  |
| `F[A => B => C] => F[A] => F[B] => F[C]` | `ap2`      | —      |
| `F[A] => F[B] => (A => B => C) => F[C]`  | `map2`     | —      |

**Пояснение:**

- **`<*` и `*>`**: позволяют выполнить два эффекта, сохраняя значение только одного из них.
- **`ap` (`<*>`)**: применяет функцию, упакованную в контекст, к значению в контексте.
- **`map2`**: применяет бинарную функцию к двум значениям в контексте.

### Applicative (Аппликативный функтор)

[`Applicative`](../../typeclass/monad/applicative.md) расширяет `Apply`, 
добавляя возможность поднять обычное значение в контекст.

| Тип                             | Имя метода | Примечания                                   |
|:--------------------------------|:-----------|:---------------------------------------------|
| `A => F[A]`                     | `pure`     | Поднимает значение в контекст                |
| `=> F[Unit]`                    | `unit`     | Создаёт `F[Unit]`                            |
| `Boolean => F[Unit] => F[Unit]` | `whenA`    | Выполняет эффект только если условие истинно |
| `Boolean => F[Unit] => F[Unit]` | `unlessA`  | Выполняет эффект только если условие ложно   |

### FlatMap (Плоское отображение)

[`FlatMap`](../../typeclass/monad/bind.md) расширяет `Apply`, добавляя возможность связывать вычисления (`flatMap`).

| Тип                                  | Имя метода |
|:-------------------------------------|:-----------|
| `F[F[A]] => F[A]`                    | `flatten`  |
| `F[A] => (A => F[B]) => F[B]`        | `flatMap`  |
| `F[A] => (A => F[B]) => F[(A, B)]`   | `mproduct` |
| `F[Boolean] => F[A] => F[A] => F[A]` | `ifM`      |
| `F[A] => (A => F[B]) => F[A]`        | `flatTap`  |

**Пояснение:**

- **`flatten`**: «разворачивает» вложенный контекст (например, `F[F[A]]` → `F[A]`).
- **`flatTap`**: выполняет эффект с побочным действием, но возвращает исходное значение.

### FunctorFilter (Функтор с фильтрацией)

`FunctorFilter` — это функтор, который позволяет фильтровать значения внутри контекста.

| Тип                                | Имя метода      | Примечания                                                    |
|:-----------------------------------|:----------------|:--------------------------------------------------------------|
| `F[A] => (A => Boolean) => F[A]`   | `filter`        | Оставляет только те значения, которые удовлетворяют предикату |
| `F[A] => (A => Option[B]) => F[B]` | `mapFilter`     | Применяет функцию, возвращающую `Option`, и фильтрует `None`  |
| `F[A] => (A => B) => F[B]`         | `collect`       | Частичная функция: применяет только к определённым значениям  |
| `F[Option[A]] => F[A]`             | `flattenOption` | Преобразует `F[Option[A]]` в `F[A]`, удаляя `None`            |

### ApplicativeError (Аппликативный функтор с обработкой ошибок)

[Этот класс типов](../../typeclass/monad/applicative-error.md) добавляет возможность работы с ошибками в аппликативном контексте. 
В исходном коде Cats для типа ошибки используется переменная `E`.

| Тип                              | Имя метода        | Примечания                                                    |
|:---------------------------------|:------------------|:--------------------------------------------------------------|
| `E => F[A]`                      | `raiseError`      | Создаёт эффект с ошибкой                                      |
| `F[A] => F[Either[E, A]]`        | `attempt`         | Преобразует ошибку в `Left` в `Either`                        |
| `F[A] => (E => A) => F[A]`       | `handleError`     | Обрабатывает ошибку, преобразуя её в значение                 |
| `F[A] => (E => F[A]) => F[A]`    | `handleErrorWith` | Обрабатывает ошибку, возвращая новый эффект                   |
| `F[A] => (E => A) => F[A]`       | `recover`         | Частичная функция для восстановления от ошибки                |
| `F[A] => (E => F[A]) => F[A]`    | `recoverWith`     | Частичная функция для восстановления с новым эффектом         |
| `F[A] => (E => F[Unit]) => F[A]` | `onError`         | Частичная функция для выполнения побочного эффекта при ошибке |
| `Either[E, A] => F[A]`           | `fromEither`      | Преобразует `Either` в эффект                                 |
| `Option[A] => E => F[A]`         | `liftFromOption`  | Преобразует `Option` в эффект, используя `E` для `None`       |

### MonadError (Монада с обработкой ошибок)

[`MonadError`](../../typeclass/monad/monad-error.md) расширяет `ApplicativeError` и `Monad`, 
добавляя методы для работы с ошибками в монадическом контексте.

| Тип                                          | Имя метода   | Примечания                                                   |
|:---------------------------------------------|:-------------|:-------------------------------------------------------------|
| `F[A] => E => (A => Boolean) => F[A]`        | `ensure`     | Проверяет условие; если ложно — возвращает ошибку `E`        |
| `F[A] => (A => E) => (A => Boolean) => F[A]` | `ensureOr`   | Проверяет условие; если ложно — вычисляет ошибку из значения |
| `F[A] => (E => E) => F[A]`                   | `adaptError` | Частичная функция для преобразования типа ошибки             |
| `F[Either[E, A]] => F[A]`                    | `rethrow`    | Преобразует `F[Either[E, A]]` в `F[A]`                       |

### UnorderedFoldable (сворачивание без сохранения порядка)

`UnorderedFoldable` — это класс типов для коллекций, где порядок элементов не имеет значения (например, множества).

| Тип                                 | Имя метода         | Ограничения                                                 |
|:------------------------------------|:-------------------|:------------------------------------------------------------|
| `F[A] => Boolean`                   | `isEmpty`          | Проверяет, пуста ли коллекция                               |
| `F[A] => Boolean`                   | `nonEmpty`         | Проверяет, не пуста ли коллекция                            |
| `F[A] => Long`                      | `size`             | Возвращает размер коллекции                                 |
| `F[A] => (A => Boolean) => Boolean` | `forall`           | Проверяет, все ли элементы удовлетворяют предикату          |
| `F[A] => (A => Boolean) => Boolean` | `exists`           | Проверяет, существует ли элемент, удовлетворяющий предикату |
| `F[A] => A`                         | `unorderedFold`    | Сворачивает коллекцию; требует `A: CommutativeMonoid`       |
| `F[A] => (A => B) => B`             | `unorderedFoldMap` | Отображает и сворачивает; требует `B: CommutativeMonoid`    |

### Foldable (Сворачиваемый)

[`Foldable`](../../typeclass/monad/foldable.md) — это класс типов для коллекций, 
поддерживающих свёртку (агрегацию) элементов в порядке их следования.

| Тип                                           | Имя метода         | Ограничения                                                             |
|:----------------------------------------------|:-------------------|:------------------------------------------------------------------------|
| `F[A] => A`                                   | `fold`             | Сворачивает коллекцию; требует `A: Monoid`                              |
| `F[A] => B => ((B, A) => B) => B`             | `foldLeft`         | Левоассоциативная свёртка с начальным значением                         |
| `F[A] => (A => B) => B`                       | `foldMap`          | Отображает и сворачивает; требует `B: Monoid`                           |
| `F[A] => (A => G[B]) => G[B]`                 | `foldMapM`         | Монадическая версия `foldMap`; требует `G: Monad` и `B: Monoid`         |
| `F[A] => (A => B) => Option[B]`               | `collectFirst`     | Частичная функция: находит первый элемент, к которому применима функция |
| `F[A] => (A => Option[B]) => Option[B]`       | `collectFirstSome` | Находит первый элемент, для которого функция возвращает `Some`          |
| `F[A] => (A => G[B]) => G[Unit]`              | `traverse_`        | Обходит и игнорирует результат; требует `G: Applicative`                |
| `F[G[A]] => G[Unit]`                          | `sequence_`        | Меняет местами эффекты, игнорируя результат; требует `G: Applicative`   |
| `F[A] => (A => Either[B, C]) => (F[B], F[C])` | `partitionEither`  | Разбивает коллекцию по `Either`; требует `G: Applicative`               |

### Reducible (Сокращаемый / Непустая коллекция)

[`Reducible`](../../typeclass/monad/reducible.md) — это класс типов для непустых коллекций, поддерживающих свёртку без начального значения.

| Тип                          | Имя метода   | Ограничения                                       |
|:-----------------------------|:-------------|:--------------------------------------------------|
| `F[A] => ((A, A) => A) => A` | `reduceLeft` | Левоассоциативная свёртка без начального значения |
| `F[A] => A`                  | `reduce`     | Сворачивает коллекцию; требует `A: Semigroup`     |

### Traverse (Обходимый)

[`Traverse`](../../typeclass/monad/traverse.md) расширяет `Foldable` и `Functor`, 
добавляя возможность обходить коллекцию с эффектами.

| Тип                                     | Имя метода           | Ограничения                                                         |
|:----------------------------------------|:---------------------|:--------------------------------------------------------------------|
| `F[G[A]] => G[F[A]]`                    | `sequence`           | Меняет местами эффекты; требует `G: Applicative`                    |
| `F[A] => (A => G[B]) => G[F[B]]`        | `traverse`           | Обходит коллекцию с эффектами; требует `G: Applicative`             |
| `F[A] => (A => G[F[B]]) => G[F[B]]`     | `flatTraverse`       | Обходит с уплощением; требует `F: FlatMap` и `G: Applicative`       |
| `F[G[F[A]]] => G[F[A]]`                 | `flatSequence`       | Последовательное уплощение; требует `G: Applicative` и `F: FlatMap` |
| `F[A] => F[(A, Int)]`                   | `zipWithIndex`       | Добавляет индекс к каждому элементу                                 |
| `F[A] => ((A, Int) => B) => F[B]`       | `mapWithIndex`       | Отображает элементы с их индексами                                  |
| `F[A] => ((A, Int) => G[B]) => G[F[B]]` | `traverseWithIndexM` | Обходит с индексами в монадическом контексте; требует `F: Monad`    |

### SemigroupK (Полугруппа для конструкторов типов)

[`SemigroupK`](../../typeclass/monoid/semigroup.md) — это версия `Semigroup` для конструкторов типов (например, для списков или опций).

| Тип                                  | Имя метода                   |
|:-------------------------------------|:-----------------------------|
| `F[A] => F[A] => F[A]`               | `combineK`                   |
| `F[A] => Int => F[A]`                | `combineNK`                  |
| `F[A] => F[B] => F[Either[A, B]]`    | `sum` (требует `F: Functor`) |
| `IterableOnce[F[A]] => Option[F[A]]` | `combineAllOptionK`          |

### MonoidK (Моноид для конструкторов типов)

[`MonoidK`](../../typeclass/monoid/monoid.md) расширяет `SemigroupK`, добавляя нейтральный элемент.

| Тип                          | Имя метода    |
|:-----------------------------|:--------------|
| `F[A]`                       | `empty`       |
| `F[A] => Boolean`            | `isEmpty`     |
| `IterableOnce[F[A]] => F[A]` | `combineAllK` |

### Alternative (Альтернатива)

[`Alternative`](../../typeclass/monad/alternative.md) объединяет `Applicative` и `MonoidK`.

| Тип                          | Имя метода         | Ограничения                                                      |
|:-----------------------------|:-------------------|:-----------------------------------------------------------------|
| `F[G[A]] => F[A]`            | `unite`            | Требует `F: FlatMap` и `G: Foldable`                             |
| `F[G[A, B]] => (F[A], F[B])` | `separate`         | Требует `F: FlatMap` и `G: Bifoldable`                           |
| `F[G[A, B]] => (F[A], F[B])` | `separateFoldable` | Требует `F: Foldable` и `G: Bifoldable`                          |
| `Boolean => F[Unit]`         | `guard`            | Выполняет эффект только если условие истинно                     |
| `IterableOnce[A] => F[A]`    | `fromIterableOnce` | Создаёт эффект из итерируемой коллекции                          |
| `G[A] => F[A]`               | `fromFoldable`     | Создаёт эффект из сворачиваемой коллекции; требует `G: Foldable` |

### NonEmptyAlternative (Непустая альтернатива)

[`NonEmptyAlternative`](../../typeclass/monad/alternative.md) расширяет `Alternative`, добавляя операции для непустых коллекций.

## Упрощения

Поскольку Cats — это библиотека для Scala, а Scala имеет множество настроек и особенностей, 
фактические определения и реализации функций и классов типов в Cats могут поначалу выглядеть сложными. 
Чтобы облегчить понимание, в этом глоссарии мы сосредоточились на простых сигнатурах типов и игнорируем многие детали Scala. 
В частности, в наших сигнатурах типов:

- Мы используем `A, B, C` для переменных типов вида `*` (обычные типы) и `F, G, H` для переменных типов высшего порядка.
- Мы записываем сигнатуры в каррированном виде: параметры принимаются по одному и разделяются стрелкой `=>`. 
  В Scala параметры метода могут быть разделены на несколько списков, разделённых запятыми.
- Мы не проводим различия между методами из трейта класса типов (например, `trait Functor`), сопутствующим объектом 
  или методом расширения.
- Для функций, определённых как методы трейта класса типов, мы игнорируем объект-получатель.
- Мы игнорируем неявные параметры, представляющие ограничения классов типов, и выносим их в отдельную колонку.
- Мы используем `A => B` как для `Function1[A, B]`, так и для `PartialFunction[A, B]`, не делая различий. 
  Мы добавляем примечание, когда речь идёт о частичной функции.
- Некоторые функции определены с использованием паттерна Partially Applied Type Params. Мы игнорируем это.
- Мы игнорируем различие между параметрами, передаваемыми по имени и по значению. 
  Мы используем обозначение `=> A` без параметров для указания константных функций.
- Мы игнорируем аннотации вариантности в Scala. Мы также игнорируем дополнительные параметры типов, 
  которые в некоторых методах добавляются с ограничением подтипа (например, `B >: A`). 
  Обычно они предназначены для гибкости, но мы заменяем каждый из них на его границу.
