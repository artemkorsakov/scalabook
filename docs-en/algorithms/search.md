# Search

Search is commonly used in everyday life, as well as in computer science.
If we perform a manual search, we are likely trying to match an image or description
that is in our mind with the actual object we are looking for.
Thus, this is a kind of pattern matching operation.
Similarly, pattern matching is a common method used in computing.
