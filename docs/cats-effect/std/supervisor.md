# Supervisor

## Мотивация

[Spawn](../typeclasses/spawn.md) предоставляет несколько способов запуска [fiber](../../../docs/cats-effect/foundation/fibers.md) для выполнения действия:

`Spawn[F]#start`: запустить и забыть, без управления жизненным циклом для запущенного волокна.

`Spawn[F]#background`: связывает жизненный цикл запущенного волокна с жизненным циклом волокна, вызвавшего `background`.

Следующие диаграммы иллюстрируют жизненный цикл запущенного волокна в обоих случаях.
В каждом примере некоторое волокно A запускает другое волокно B.
Каждый прямоугольник представляет жизненный цикл волокна.
Если прямоугольник заключен внутри другого прямоугольника, это означает, что жизненный цикл первого ограничен жизненным циклом второго.
Другими словами, если внешнее волокно завершается, гарантируется, что внутренние волокна также завершатся.


`Spawn[F]#start`:
```
Жизненный цикл волокна A
+---------------------+
| | |

+-----------------|---+
|

|A запускает B
Жизненный цикл волокна B |

+-----------------|---+
| + |

+---------------------+
```

`Spawn[F]#background`:
```
Жизненный цикл волокна A
+------------------------+
| | |

| Жизненный цикл волокна B |A запускает B
| +------------------|-+ |

| | | | |
| +--------------------+ |

+------------------------+
```

Но что, если мы хотим создать волокно, которое должно просуществовать дольше, чем область, которая его создала,
но мы все еще хотим контролировать его жизненный цикл?

## Супервизор

Супервизор создает волокна, жизненные циклы которых привязаны к жизненному циклу супервизора.

```scala
trait Supervisor[F[_]] {
def supervise[A](fa: F[A]): ​​F[Fiber[F, Throwable, A]]
}

object Supervisor {
def apply[F[_]](await: Boolean)(implicit F: Concurrent[F]): Resource[F, Supervisor[F]]
}
```

Любые волокна, созданные с помощью супервизора, будут финализированы, когда сам супервизор
будет финализирован с помощью `Resource#use`.

Жизненный цикл волокон, созданных с помощью `Supervisor`, можно проиллюстрировать в том же стиле, что и выше:

```
Жизненный цикл супервизора
+---------------------+
| Жизненный цикл волокна B |

| +-----------------+ |

| | + | |

| +---------------|-+ |

+-----------------|---+

|
| A начинает B
Жизненный цикл волокна A |

+-----------------|---+
| | |

+---------------------+
```

Существуют две стратегии завершения в соответствии с параметром `await` конструктора:
- `true` - ожидание завершения активных волокон
- `false` - отмена активных волокон

**Примечание:** если эффект, который никогда не завершается, контролируется `Supervisor` с политикой ожидания завершения, завершение `Supervisor` приостанавливается на неопределенный срок:
```scala mdoc:silent
import cats.effect.IO
import cats.effect.std.Supervisor

Supervisor[IO](await = true).use { supervisor =>

  supervisor.supervise(IO.never).void
}
```
