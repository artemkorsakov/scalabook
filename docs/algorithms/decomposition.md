# Декомпозиция задач

В этой главе представлены общие способы решения задач путем разбиения на более простые. 
Объединяет их одна мысль: сложную задачу часто можно свести к нескольким простым подзадачам, 
решить каждую из них быстрее, чем исходную целиком, а затем «склеить» результаты.

## Содержание главы

- **Сканирующая прямая** (`decomposition/scanning_line.md`) — сортировка «событий» и проход по ним слева направо. 
  Разбирается на примерах точки, покрытой максимальным числом отрезков, длины их объединения, 
  количества запросов на прямоугольники и площади объединения прямоугольников.
- **Откатывание состояний** (`decomposition/rollback.md`) — «буферизация» запросов и периодическая перестройка статической структуры: 
  работает, когда достаточно научиться откатываться на несколько шагов назад, а не на сотни.
- **Meet-in-the-middle** (`decomposition/mitm.md`) — «встреча в середине»: перебор \\(O(2^n)\\) разбивается 
  на два перебора по \\(O(2^{n/2})\\) с последующей склейкой ответов.
- **Корневые эвристики** (`decomposition/sqrt-heuristics.md`) — техника, основанная на равенстве \\(\sqrt x = \frac{x}{\sqrt x}\\): 
  больших объектов мало, маленькие — маленькие.
- **Алгоритм Мо** (`decomposition/mo.md`) — оффлайн-обработка запросов на подотрезках, сгруппированных по корневым блокам.

## Общая идея

Пусть есть задача размера \\(n\\), которую в лоб можно решить за \\(O(f(n))\\), где \\(f(n)\\) — «слишком большая» функция. 
Декомпозиция пытается построить решение вида

\\(O(g(n) + h(n)), \qquad g(n) \ll f(n), \quad h(n) \ll f(n),\\)

где \\(g\\) и \\(h\\) достигают своей малости благодаря тому, что задача разбивается на блоки размера около \\(\sqrt n\\), 
либо перебор делится на две независимые половины.

Например, в алгоритме Мо запросы делятся на \\(\sqrt n\\) блоков по левой границе, 
а сканирующая прямая работает потому, что «интересных» точек-событий ровно \\(2n\\). 
Везде в этой главе ключевой приём — грамотно **упорядочить** пространство задач (по координате, по блоку, по степени), 
чтобы локально решать маленькие куски за дёшево.
