# Структуры управления

В Scala есть все ожидаемые структуры управления, в том числе:

- [`if`/`then`/`else`](structures/ifelse.md)
- [циклы `for`](structures/for.md)
- [циклы `while`](structures/others.md)
- [`try`/`catch`/`finally`](structures/others.md)

Здесь также есть две другие мощные конструкции, присутствующие не во всех языках программирования:

- [`for` выражения (также известные как _for comprehensions_)](structures/for.md)
- [`match` выражения](structures/match.md)
