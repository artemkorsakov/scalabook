# Sorting

Sorting is a common operation both in life and in computer science.
In our everyday lives, we sort elements to make searching faster, which is also true in the field of computer science.
After all, computers exist to help us with everyday tasks.
Sorting can occur at different levels depending on the requirements.
For example, sometimes we might need to sort character by character.
In other cases, we might need to sort larger structures, such as company profiles.
Whatever the reason, the basic principle of sorting remains the same.

In addition, there are two sorting orders — ascending and descending.
Suppose we need to sort n elements: \\(a\_{1}, a\_{2}, a\_{3}, ..., a\_{n}\\}.
When these elements are sorted in ascending order,
their relationship can be formally stated as \\(a\_{1} \leq a\_{2} \leq a\_{3} \leq ... \leq a\_{n}\\}.
Similarly, their sorting in descending order can be formally stated
as \\(a\_{1} \geq a\_{2} \geq a\_{3} \geq ... \geq a\_{n}\\}.
