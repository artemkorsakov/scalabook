# Линейный поиск

> [Линейный, последовательный поиск](https://ru.wikipedia.org/wiki/%D0%9B%D0%B8%D0%BD%D0%B5%D0%B9%D0%BD%D1%8B%D0%B9_%D0%BF%D0%BE%D0%B8%D1%81%D0%BA) — 
алгоритм нахождения заданного значения произвольной функции на некотором отрезке.

**Алгоритм:**

- **Шаг 1** (Начало). Входные данные - список `list` и ключ `key`, который нужно найти.
- **Шаг 2** (Проверка на пустоту). Если список `list` пустой, вернуть `None`, так как элемент не найден.
- **Шаг 3** (Сравнение с первым элементом). Если первый элемент списка равен искомому ключу, вернуть `Some(key)` - это означает, что элемент найден.
- **Шаг 4** (Рекурсивный вызов) Если первый элемент не равен ключу, рекурсивно вызвать функцию с оставшейся частью списка.
- **Шаг 5** (Завершение). Процесс повторяется, пока не будет найден элемент или не будет достигнут конец списка.

**Пример:**

Рассмотрим пример, где у нас есть список чисел и мы ищем число `3`:

- Первый вызов: `list = List(1, 2, 3, 4, 5), key = 3`. Список не пустой, первый элемент `1` не равен `3`.
- Второй вызов: `list = List(2, 3, 4, 5), key = 3`. Список не пустой, первый элемент `2` не равен `3`.
- Третий вызов: `list = List(3, 4, 5), key = 3`. Список не пустой, первый элемент `3` равен `3`.
- Возвращаем `Some(3)`.

Таким образом, результатом выполнения функции будет `Some(3)`, что означает, что элемент найден. 
Если бы мы искали, например, число `6`, то функция продолжила бы вызывать себя до тех пор, пока не дошла бы до пустого списка, и в итоге вернула бы `None`.

**Оценка:**

- **Время**:
    - Худшее - \\(O(n)\\)
    - Лучшее - \\(O(1)\\)
    - Среднее - \\(O(n)\\)
- **Память** - \\(O(1)\\)

**Код:**

```dotty
@tailrec
def linearSearch[A](list: List[A], key: A): Option[A] =
  list match
    case Nil                      => None
    case head :: _ if head == key => Some(key)
    case _ :: tail                => linearSearch(tail, key)

val text   = "This is a functional implementation."
linearSearch(text.toList, 'a')  
// Some(a)
```
